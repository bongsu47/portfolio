# \[2] 쇼케이스 세팅

{% hint style="warning" icon="triangle-exclamation" %}
여기서부터는 **Admin 계정**에서 진행해주세요!
{% endhint %}

`쇼케이스` 는 **조직 내에서 활용 가능한 앱**들을 한눈에 살펴볼 수 있도록 구성된 메인 랜딩 페이지입니다.

조직 차원에서 1) 권장하는 표준 앱과, 2) 구성원이 직접 만들어 활발히 사용되고 있는 앱을 함께 보여줌으로써, 사용자가 자신의 업무에 맞는 앱을 쉽게 발견하고 활용할 수 있도록 돕습니다.

쇼케이스는 다음 2개의 섹션으로 구성됩니다.

1.  **인기 템플릿**

    일반 업무에 두루 적용할 수 있는 `공용 기본앱`이 노출되는 섹션으로, 조직 차원에서 권장하는 대표 앱들로 구성됩니다.

{% hint style="info" %}
**Admin 계정에서 업로드한 앱만** 이 섹션에 등록됩니다.
{% endhint %}

2.  **동료가 만든 앱**

    구성원이 직접 제작해 전체 공유한 앱이 표시되는 섹션으로, 현업에서 만들어진 실무 앱들이 노출됩니다.

{% hint style="info" %}
**사용량 기준 내림차순으로 정렬**되어, 조직 내에서 가장 활발히 활용되고 있는 앱을 한눈에 확인하실 수 있습니다.
{% endhint %}

<details>

<summary><strong>1단계: 쇼케이스 앱 등록</strong></summary>

<figure><img src="../.gitbook/assets/image (746).png" alt=""><figcaption></figcaption></figure>

`쇼케이스` 기본 페이지 중 `인기 템플릿` 탭에 **법령 검색 에이전트**를 추가해보겠습니다.



<figure><img src="../.gitbook/assets/image (747).png" alt=""><figcaption></figcaption></figure>

좌측 패널에서 쇼케이스 를 클릭하여 들어가줍니다.



<figure><img src="../.gitbook/assets/image (748).png" alt=""><figcaption></figcaption></figure>

스크롤을 내려 **법령 검색 에이전트**를 찾은 뒤, 오른쪽 `노출 상태` 체크박스를 체크해줍니다.



<figure><img src="../.gitbook/assets/image (749).png" alt=""><figcaption></figcaption></figure>

1. `변경사항 저장` 을 해준 뒤
2. `쇼케이스 작업 실행` 을 눌러줍니다.

{% hint style="info" %}
변경사항 저장 : **관리자 계정**에서 확인할 쇼케이스 목록 설정

쇼케이스 작업 실행 : **모든 계정**에서도 쇼케이스 화면에서 볼 목록을 Update 해주는 버튼



목록 뿐만 아니라, ‘사용량’ 에 따른 노출 순위를 Update 할 때도 사용하기 때문에 2개의 버튼은 구분되어 있습니다.
{% endhint %}

<figure><img src="../.gitbook/assets/image (750).png" alt=""><figcaption></figcaption></figure>

이후 각 계정별로 `쇼케이스` 에 들어가보면 **법령 검색 에이전트**가 인기 템플릿 영역에 추가된 것을 확인할 수 있습니다.

</details>

<details>

<summary><strong>2단계: 쇼케이스 업데이트</strong></summary>

**option 1 : 자동 업데이트**

<figure><img src="../.gitbook/assets/image (751).png" alt=""><figcaption></figcaption></figure>

쇼케이스 작업 실행 버튼을 누르면, 사용량을 기준으로 ‘동료가 만든 앱’ 상위 11개가 자동 선택됩니다.

이때, 인기 템플릿은 Admin이 직접 선택한 것이기 때문에 자동 선택 범위에서 제외되며, 기존에 설정한 상태 그대로 유지됩니다.

***

**option2 : 수동 업데이트**

<figure><img src="../.gitbook/assets/image (752).png" alt=""><figcaption></figcaption></figure>

우측의 `노출 상태` 체크 박스를 통해서 쇼케이스 화면에서 보여주고 싶은 앱 목록을 수동으로 선택할 수 있습니다.

<figure><img src="../.gitbook/assets/image (753).png" alt=""><figcaption></figcaption></figure>

이후, 좌상단의 `변경사항 저장` 을 클릭하면, 쇼케이스 화면에 반영됩니다.

</details>
