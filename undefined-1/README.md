# 미소 온보딩 가이드

{% hint style="info" icon="bullhorn" %}
**이 가이드에서 하는 일**

미소 관리자가 기본 앱을 등록하고, 구성원이 사용할 수 있도록 쇼케이스에 등록하는 과정을 안내합니다.



**이 가이드를 완료하면 다음 작업을 할 수 있습니다.**

1. 기본 앱 파일을 다운받아 MISO에 등록합니다.
2. 등록한 앱을 조직 구성원이 사용할 수 있도록 발행·공유합니다.
3. 쇼케이스의 인기 템플릿과 동료가 만든 앱 영역을 설정합니다.
{% endhint %}

{% hint style="warning" %}
진행 과정 중에 모르겠는 부분이 생기시면 Slack @MISO Support 챗봇 혹은 **MISO팀**([miso@gs.co.kr](mailto:miso@gs.co.kr))에 문의해주세요!
{% endhint %}
