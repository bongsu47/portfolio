# 지식 공유하기

### 지식 권한

{% hint style="info" %}
지식의 권한과 공유 범위는 [앱 공유하기](app.md)와 같은 방식으로 설정합니다.
{% endhint %}

#### 사용자

앱에서 참조한 지식을 사용할 수 있습니다.

지식을 구성하는 문서, 청크, 상세 정보를 확인할 수 있습니다.

#### 편집자

사용자 권한에 더해 지식 설정을 수정하고 문서를 추가로 임베딩할 수 있습니다.

편집자 권한은 같은 워크스페이스 사용자에게만 부여할 수 있습니다.

### 공유 범위

#### 비공개

지식을 등록한 사용자만 사용할 수 있습니다.

#### 현재 워크스페이스 공개

현재 워크스페이스 사용자에게 지식 사용 권한을 부여합니다.

사용자별 추가 권한이 없으면 앱에서 연동 지식으로만 사용할 수 있습니다.

#### 모든 워크스페이스 공개

모든 워크스페이스 사용자에게 지식 사용 권한을 부여합니다.

사용자별 추가 권한이 없으면 앱에서 연동 지식으로만 사용할 수 있습니다.

#### 외부 공개

외부 사용자도 지식을 사용할 수 있습니다.

외부 공개 앱에서 참조하는 지식도 **외부 공개**로 설정해야 합니다.

#### 부분 공개

특정 사용자에게만 사용자 권한을 부여합니다.

{% hint style="info" %}
외부 서비스에서 API로 MISO 앱과 지식을 호출할 때는 앱과 지식을 모두 **외부 공개**로 설정해야 합니다.
{% endhint %}
