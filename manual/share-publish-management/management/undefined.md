# 에이전트 사용 현황 대시보드

<figure><img src="../../../.gitbook/assets/image (836).png" alt=""><figcaption></figcaption></figure>

발행된 에이전트 앱의 대화량, 사용자, 토큰 및 크레딧 사용량을 확인합니다.

앱 구성 화면에서 **사용 현황 보기**를 선택하세요. 에이전트 대시보드는 대화 단위로 지표와 로그를 제공합니다.

### 대시보드 탭

<figure><img src="../../../.gitbook/assets/image (837).png" alt=""><figcaption></figcaption></figure>

| 탭             | 설명                                  |
| ------------- | ----------------------------------- |
| **사용현황 모니터링** | 메시지 수, 사용자, 토큰·크레딧 등 핵심 지표를 시각화합니다. |
| **로그**        | 대화 단위의 상세 이력을 확인합니다.                |
| **사용자 의견보기**  | 사용자가 남긴 좋아요/아쉬워요 피드백을 확인합니다.        |

#### 날짜 범위

오른쪽 상단의 **날짜 범위 선택기**에서 조회 기간을 설정합니다. 기본값은 **오늘을 포함한 최근 7일**입니다.

달력은 두 달을 함께 표시합니다. 미래 날짜는 선택할 수 없습니다. 선택한 기간은 모든 탭에 적용됩니다.

### 사용현황 모니터링

에이전트 앱의 핵심 사용 지표를 확인합니다.

<figure><img src="../../../.gitbook/assets/image (838).png" alt=""><figcaption></figcaption></figure>

#### 개요 카드

| 지표                  | 설명                                 |
| ------------------- | ---------------------------------- |
| **총 메시지 수**         | 선택 기간 내 발생한 총 메시지 수                |
| **활성화 사용자 수**       | 일별 고유 사용자 수를 응답된 일수로 나눈 평균         |
| **평균 대화 수**         | 대화당 메시지 수의 일별 평균                   |
| **토큰 출력 속도 (토큰/초)** | 응답 토큰 수를 응답 지연시간으로 나눈 일별 값         |
| **토큰 총 사용량**        | 입력·출력 토큰의 합계                       |
| **크레딧 사용량**         | 선택 기간 내 크레딧 사용량 합계 (소수 둘째 자리까지 표시) |

#### 차트

| 차트               | 유형      | 내용            |
| ---------------- | ------- | ------------- |
| **메시지 수 추이**     | 꺾은선 그래프 | 일별 메시지 수      |
| **활성화 사용자 수 추이** | 꺾은선 그래프 | 일별 고유 사용자 수   |
| **평균 대화 수 추이**   | 꺾은선 그래프 | 일별 평균 대화 수    |
| **토큰 출력 속도 추이**  | 꺾은선 그래프 | 일별 토큰/초       |
| **토큰 사용량 추이**    | 막대 그래프  | 입력 토큰 / 출력 토큰 |
| **크레딧 사용량 추이**   | 막대 그래프  | 일별 크레딧 사용량    |

{% hint style="info" %}
이 화면에는 오류율, API 호출 수, 인기 페이지 TOP N 같은 지표가 없습니다. \
해당 지표는 웹사이트 앱 대시보드에서만 제공됩니다.
{% endhint %}

### 로그

대화 단위의 상세 이력을 확인합니다. 검색과 페이지당 15건의 페이지네이션을 제공합니다. 대화 로그는 ZIP 파일로 내려받을 수 있습니다.

<figure><img src="../../../.gitbook/assets/image (839).png" alt=""><figcaption></figcaption></figure>

#### 목록 열

| 열              | 설명               |
| -------------- | ---------------- |
| **시간**         | 대화 발생 시각         |
| **사용자**        | 대화를 발생시킨 사용자     |
| **첫 질문**       | 대화의 첫 사용자 메시지 요약 |
| **메시지 수**      | 해당 대화에 포함된 메시지 수 |
| **사용 환경**      | 대화가 발생한 접속 환경    |
| **좋아요 / 아쉬워요** | 사용자가 남긴 피드백      |
| **상세(메시지)**    | 대화의 전체 메시지 보기    |

#### 상세 보기

대화별 질문과 응답, 토큰 사용량, 피드백, 에이전트의 사고 과정을 확인할 수 있습니다.

첫 메시지에 입력 변수가 있으면 별도 패널에서 함께 표시합니다.

### 사용자 의견보기

사용자가 남긴 **좋아요/아쉬워요 피드백**을 확인합니다. 기간과 피드백 유형으로 필터링하거나 검색할 수 있습니다. 결과는 Excel 파일로 내려받을 수 있습니다.
