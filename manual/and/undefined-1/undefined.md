# 도구 이해하기

### 개요

도구는 AI가 외부 서비스와 연결해 작업을 수행하는 확장 기능입니다.

AI는 도구로 다음 작업을 수행할 수 있습니다.

* 실시간 웹 검색과 데이터 분석
* 사내 시스템 및 외부 서비스의 데이터 조회와 수정
* 이미지와 문서 생성, 조직 API 호출

### 도구 공급과 활용

도구를 준비하는 관리자와 활용하는 제작자의 역할은 다릅니다.

<table><thead><tr><th width="102.3333740234375">구분</th><th width="437.3333740234375">하는 일</th><th>담당</th></tr></thead><tbody><tr><td>도구 공급</td><td>도구 API 연결, 인증정보 등록, 도구 활성화</td><td>관리자</td></tr><tr><td>도구 활용</td><td>공급된 도구를 골라 Agent·워크플로우·웹사이트에 붙여 사용</td><td>제작자 (여러분)</td></tr></tbody></table>

제작자는 관리자가 연결한 도구를 선택해 앱에 추가합니다.

{% hint style="info" %}
도구가 없거나 비활성화되었다면 관리자에게 공급 또는 활성화를 요청하세요.
{% endhint %}

### 도구의 종류

도구 선택 화면은 세 가지 탭으로 구성됩니다.

#### 기본 도구

MISO에서 제공하는 도구입니다. 웹 검색, 이미지 생성, 문서 생성, 데이터 분석을 사용할 수 있습니다.

조직 공용 도구와 개인 계정으로 연결하는 도구가 함께 표시됩니다.

<figure><img src="../../../.gitbook/assets/image (845).png" alt=""><figcaption></figcaption></figure>

#### 워크플로우

만든 워크플로우를 하나의 도구처럼 재사용합니다.

자주 사용하는 처리 과정은 워크플로우로 구성해 다른 앱에서 호출할 수 있습니다.

<figure><img src="../../../.gitbook/assets/image (846).png" alt=""><figcaption></figcaption></figure>

#### 외부 연동

관리자가 연결한 커스텀 API와 외부 서버(MCP)를 사용합니다.

조직 전용 시스템이나 외부 서비스를 연결할 때 활용합니다.

### 도구를 어디에 쓰나요?

같은 도구도 앱 유형에 따라 호출 방식이 달라집니다.

| 사용 위치       | 동작 방식                   | 사용 시점               |
| ----------- | ----------------------- | ------------------- |
| **Agent 앱** | AI가 상황에 맞춰 도구를 호출합니다.   | 도구 선택을 AI에 맡길 때     |
| **워크플로우**   | 정해진 단계에서 도구를 실행합니다.     | 실행 순서와 시점을 통제할 때    |
| **웹사이트 앱**  | 코딩 에이전트가 도구를 코드에 구현합니다. | 방문자 동작에 맞춘 기능을 만들 때 |

자세한 설정 방법은 [도구 설정하기](../../agent/undefined-3.md), [워크플로우 이해하기](../../workflow/undefined.md), [플러스(+) 버튼](../../website/undefined-1/+.md)에서 확인하세요.

### 인증

외부 서비스에 접근하는 도구는 인증이 필요할 수 있습니다.

인증 정보의 저장 위치는 도구 유형에 따라 다릅니다.

<table><thead><tr><th width="215.3333740234375">도구 종류</th><th>인증 방식</th></tr></thead><tbody><tr><td>조직 공용 도구</td><td>관리자가 워크스페이스에 한 번 등록 (제작자는 별도 등록 불필요)</td></tr><tr><td>워크플로우 도구</td><td>별도 인증정보 없음</td></tr></tbody></table>

앱은 인증 정보를 저장하지 않습니다. 앱에는 사용할 도구와 입력값만 저장됩니다.

### 문제 해결

도구가 표시되고 실행되려면 다음 조건을 모두 충족해야 합니다.

1. **활성화**: 관리자가 도구를 워크스페이스에 공급하고 활성화했습니다.
2. **인증**: 공용 인증 정보가 등록됐거나 개인 계정이 연결됐습니다.
3. **선택**: 앱에 도구를 추가했습니다.

{% hint style="info" %}
일부 도구는 실행 전 승인이 필요합니다. 필요한 경우 실행 시 확인 절차가 표시됩니다.
{% endhint %}

문제가 계속되면 활성화와 인증 상태를 관리자에게 확인하세요.

### 활용 팁

* 도구 선택을 AI에 맡기려면 **Agent**를 사용하세요.
* 실행 순서를 통제하려면 워크플로우에 도구를 추가하세요.
* 웹사이트 도구는 원하는 동작을 요청해 코드에 구현하세요.
* 도구 목록은 워크스페이스 설정과 배포 옵션에 따라 달라질 수 있습니다.
