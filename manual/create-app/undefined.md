# 템플릿으로 시작하기

#### 접근 경로

* **앱 만들기 > 템플릿으로 시작하기**



<figure><img src="../../.gitbook/assets/스크린샷 2026-07-02 오후 5.57.55.png" alt=""><figcaption></figcaption></figure>

#### 템플릿 둘러보기

* 화면에는 **나에게 노출된 템플릿**만 표시됩니다. (내 소속 고객사에 맞는 템플릿 + 공통 템플릿)
* 검색창에서 앱 이름으로 찾을 수 있습니다.
* 지식이 포함된 템플릿에는 **지식 배지**가 표시됩니다.

<figure><img src="../../.gitbook/assets/image (819).png" alt=""><figcaption></figcaption></figure>

#### 템플릿으로 앱 만들기

1. 원하는 **템플릿 카드를 선택**합니다.
2. **앱 이름·설명** 등 기본 정보를 입력합니다.
3. **만들기**를 누르면 템플릿의 구성(DSL)을 기반으로 앱이 자동으로 만들어집니다.
4. 완료되면 앱 편집 화면으로 이동합니다.

<figure><img src="../../.gitbook/assets/image (820).png" alt=""><figcaption></figcaption></figure>

#### 앱을 만들 때 자동으로 맞춰지는 것

내 워크스페이스 환경에 맞게 템플릿의 도구·모델이 자동으로 점검·조정됩니다.

**도구**

* 템플릿에 **활성화되지 않은 도구**가 포함되어 있으면 앱을 만들 수 없습니다. 생성 버튼이 비활성화되고 _"활성화되지 않은 도구가 포함되어 있어 앱을 생성할 수 없습니다. 도구모음에서 활성화한 후 다시 시도해 주세요."_ 안내가 표시됩니다.
* 이 경우 **관리자에게 해당 도구 활성화를 요청**하세요.

**LLM 모델**

* 사용할 수 있는 LLM이 **하나도 없으면** 앱을 만들 수 없습니다. (관리자가 모델 관리에서 LLM을 먼저 활성화해야 합니다.)
* 템플릿에 지정된 LLM이 내 워크스페이스에 없으면, **워크스페이스 기본 모델 → 고객사 기본 모델** 순서로 자동 대체되어 앱이 만들어집니다.

**지식(임베딩) 모델**

* **지식(샘플 문서)이 포함된 템플릿**은 임베딩 모델이 있어야 만들 수 있습니다. 임베딩 모델이 없으면 _"임베딩 모델이 설정되어 있지 않습니다..."_ 안내와 함께 만들 수 없습니다.
* 임베딩 모델이 있으면, LLM과 동일하게 **워크스페이스 기본 → 고객사 기본** 순으로 적용됩니다.
* 지식이 없는 템플릿은 임베딩 모델 없이도 만들 수 있습니다.

**리랭킹(Reranking) 모델**

* 템플릿에 지정된 리랭킹 모델이 내 워크스페이스에 있으면 그대로 사용합니다.
* 지정된 리랭킹 모델이 없으면, **리랭킹을 끄고** 앱을 만듭니다. (검색 품질에는 영향이 있을 수 있으나 앱 생성은 정상 진행됩니다.)

**한눈에 보기**

| 상황                | 결과                        |
| ----------------- | ------------------------- |
| 활성화 안 된 도구 포함     | ❌ 생성 불가 — 도구 활성화 후 재시도    |
| 사용 가능한 LLM 전혀 없음  | ❌ 생성 불가                   |
| 템플릿 LLM이 없음       | ✅ 워크스페이스 기본 → 고객사 기본으로 대체 |
| (지식 포함) 임베딩 모델 없음 | ❌ 생성 불가                   |
| (지식 포함) 임베딩 모델 있음 | ✅ 워크스페이스 기본 → 고객사 기본으로 적용 |
| 템플릿 리랭킹 모델이 없음    | ✅ 리랭킹을 끄고 진행              |

#### 지식이 포함된 템플릿

지식(샘플 문서)이 포함된 템플릿을 선택하면, 앱 생성 후 샘플 문서가 **내 데이터셋으로 자동 임베딩**됩니다.

* 임베딩 진행 상태가 화면에 표시되며, 완료되면 앱의 지식으로 연결됩니다.
* 같은 템플릿으로 앱을 다시 만들면, 이미 임베딩된 지식을 **재사용**하여 다시 임베딩하지 않습니다.

### 자주 묻는 질문

**Q. 지식 임베딩이 오래 걸려요.**

* 샘플 문서의 크기와 수에 따라 임베딩 시간이 달라집니다. 진행 상태가 표시되며, 완료 후 앱에서 지식을 사용할 수 있습니다.

**Q. 템플릿으로 만든 앱을 수정할 수 있나요?**

* 네. 생성된 앱은 일반 앱과 동일하게 편집·발행할 수 있습니다.
