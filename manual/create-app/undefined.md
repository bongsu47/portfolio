# 템플릿으로 시작하기

미리 만들어진 앱 템플릿을 골라 몇 번의 클릭으로 새 앱을 만들 수 있습니다.

### 접근 경로

* **앱 만들기 > 템플릿으로 시작하기**

<figure><img src="../../.gitbook/assets/스크린샷 2026-06-29 오후 2.50.17.png" alt=""><figcaption></figcaption></figure>

### 템플릿 둘러보기

* 화면에는 **나에게 노출된 템플릿**만 표시됩니다.
  * 내 소속(고객사)의 산업그룹에 맞는 템플릿 + 모든 고객사 공통(범용) 템플릿
* 상단의 **산업그룹(카테고리) 태그**로 목록을 좁혀 볼 수 있습니다.
* 검색창에서 앱 이름으로 찾을 수 있습니다.
* 지식이 포함된 템플릿에는 **지식 배지**가 표시됩니다.

<figure><img src="../../.gitbook/assets/image (794).png" alt=""><figcaption></figcaption></figure>

### 템플릿으로 앱 만들기

1. 원하는 **템플릿 카드를 선택**합니다.
2. **앱 이름·설명** 등 기본 정보를 입력합니다.
3. **만들기**를 누르면 템플릿의 구성(DSL)을 기반으로 앱이 자동으로 만들어집니다.
4. 완료되면 앱 편집 화면으로 이동합니다.



### 지식이 포함된 템플릿

지식(샘플 문서)이 포함된 템플릿을 선택하면, 앱 생성 후 샘플 문서가 **내 데이터셋으로 자동 임베딩**됩니다.

* 임베딩 진행 상태가 화면에 표시되며, 완료되면 앱의 지식으로 연결됩니다.
* 같은 템플릿으로 앱을 다시 만들면, 이미 임베딩된 지식을 **재사용**하여 다시 임베딩하지 않습니다.

### 자주 묻는 질문

**Q. 보고 싶은 템플릿이 목록에 없어요.**

* 템플릿은 산업그룹별로 노출됩니다. 내 소속 고객사의 산업그룹에 맞는 템플릿과 범용 템플릿만 보입니다. 필요한 템플릿이 없다면 관리자에게 문의하세요.

**Q. 지식 임베딩이 오래 걸려요.**

* 샘플 문서의 크기와 수에 따라 임베딩 시간이 달라집니다. 진행 상태가 표시되며, 완료 후 앱에서 지식을 사용할 수 있습니다.

**Q. 템플릿으로 만든 앱을 수정할 수 있나요?**

* 네. 생성된 앱은 일반 앱과 동일하게 편집·발행할 수 있습니다.
