# 워크플로우 사용 현황 대시보드

<figure><img src="../../../.gitbook/assets/image (841).png" alt=""><figcaption></figcaption></figure>

발행된 워크플로우 앱의 실행량, 사용자, 토큰 및 크레딧 사용량을 확인합니다.

앱 구성 화면에서 **사용 현황 보기**를 선택하세요. 워크플로우 대시보드는 실행(run) 단위로 지표와 로그를 제공합니다.

### 대시보드 탭

<figure><img src="../../../.gitbook/assets/image (842).png" alt=""><figcaption></figcaption></figure>

| 탭             | 설명                                 |
| ------------- | ---------------------------------- |
| **사용현황 모니터링** | 실행 수, 사용자, 토큰·크레딧 등 핵심 지표를 시각화합니다. |
| **로그**        | 실행(run) 단위의 상세 이력을 확인합니다.          |
| **사용자 의견보기**  | 사용자가 남긴 좋아요/아쉬워요 피드백을 확인합니다.       |

#### 날짜 범위

오른쪽 상단의 **날짜 범위 선택기**에서 조회 기간을 설정합니다. 기본값은 **오늘을 포함한 최근 7일**입니다.

달력은 두 달을 함께 표시합니다. 미래 날짜는 선택할 수 없습니다. 선택한 기간은 모든 탭에 적용됩니다.

### 사용현황 모니터링

워크플로우 앱의 핵심 사용 지표를 확인합니다.

<figure><img src="../../../.gitbook/assets/스크린샷 2026-07-24 161325.png" alt=""><figcaption></figcaption></figure>

#### **개요 카드**

| 지표            | 설명                                 |
| ------------- | ---------------------------------- |
| **총 메시지 수**   | 선택 기간 내 총 실행(run) 수                |
| **활성화 사용자 수** | 일별 고유 실행 사용자 수를 응답된 일수로 나눈 평균      |
| **평균 대화 수**   | 사용자당 실행 수의 일별 평균                   |
| **토큰 총 사용량**  | 입력·출력 토큰의 합계                       |
| **크레딧 사용량**   | 선택 기간 내 크레딧 사용량 합계 (소수 둘째 자리까지 표시) |

#### 차트

| 차트               | 유형      | 내용              |
| ---------------- | ------- | --------------- |
| **메시지 수 추이**     | 꺾은선 그래프 | 일별 실행(run) 수    |
| **활성화 사용자 수 추이** | 꺾은선 그래프 | 일별 고유 사용자 수     |
| **평균 대화 수 추이**   | 꺾은선 그래프 | 일별 사용자당 평균 실행 수 |
| **토큰 사용량 추이**    | 막대 그래프  | 입력 토큰 / 출력 토큰   |
| **크레딧 사용량 추이**   | 막대 그래프  | 일별 크레딧 사용량      |

{% hint style="info" %}
**총 메시지 수**와 **평균 대화 수** 라벨은 에이전트 앱과 공유되어 그대로 표기되지만, 워크플로우 앱에서는 각각 **실행(run) 수**와 **사용자당 실행 수**를 의미합니다. 또한 워크플로우 앱에는 에이전트에 있는 **토큰 출력 속도(토큰/초)** 지표와 차트가 없습니다.
{% endhint %}

### 로그

실행(run) 단위의 상세 이력을 확인합니다. 검색과 페이지당 15건의 페이지네이션을 제공합니다. 실행 로그는 ZIP 파일로 내려받을 수 있습니다.

<figure><img src="../../../.gitbook/assets/image (843).png" alt=""><figcaption></figcaption></figure>

#### 목록 열

| 열              | 설명                    |
| -------------- | --------------------- |
| **시간**         | 실행 발생 시각              |
| **사용자**        | 실행을 발생시킨 사용자          |
| **출력**         | 실행 결과 출력 요약           |
| **단계 수**       | 실행에 포함된 노드 단계(step) 수 |
| **사용 환경**      | 실행이 발생한 접속 환경         |
| **좋아요 / 아쉬워요** | 사용자가 남긴 피드백           |
| **상세(실행로그)**   | 실행 상세 보기              |

#### 상세 보기

실행의 입력 및 출력(JSON), 상태, 실행 시간, 총 토큰 사용량, 오류를 확인할 수 있습니다.

**실행 로그**를 선택하면 각 노드의 실행 추적을 확인할 수 있습니다. 입력 변수는 실행 상세의 **Inputs**에서 확인합니다.

### 사용자 의견보기

사용자가 남긴 **좋아요/아쉬워요 피드백**을 확인합니다. 기간과 피드백 유형으로 필터링하거나 검색할 수 있습니다. 결과는 Excel 파일로 내려받을 수 있습니다.
