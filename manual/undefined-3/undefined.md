# 도구 이해하기

## 도구 이해하기

도구는 AI가 외부 서비스와 연결해 작업을 수행하는 확장 기능입니다.

AI는 도구로 다음 작업을 수행할 수 있습니다.

* 실시간 웹 검색과 데이터 분석
* 사내 시스템 및 외부 서비스의 데이터 조회와 수정
* 이미지와 문서 생성, 조직 API 호출

### 도구 유형

도구 모음에서는 네 가지 유형의 도구를 확인할 수 있습니다.

#### 기본 도구

MISO에서 제공하는 도구입니다. 웹 검색, 이미지 생성, 문서 생성, 데이터 분석에 사용합니다.

[기본 도구](undefined-1.md)에서 제공 도구와 앱별 활용 방법을 확인합니다.

#### 워크플로우

만든 워크플로우를 하나의 도구처럼 재사용합니다. 정해진 순서의 반복 작업을 다른 앱에서 호출할 때 사용합니다.

[워크플로우 도구](undefined-2.md)에서 사용 시점과 등록 방법을 확인합니다.

#### 에이전트

만든 에이전트를 다른 에이전트가 사용할 수 있는 도구로 등록합니다. 여러 전문 에이전트를 조합해야 할 때 사용합니다.

[에이전트](undefined-3.md)에서 등록과 활용 방법을 확인합니다.

#### 외부 연동

관리자가 연결한 커스텀 API와 외부 서버(MCP)를 사용합니다. 조직 전용 시스템이나 외부 서비스를 연결할 때 적합합니다.

[외부 연동](undefined-4.md)에서 연결된 도구를 확인합니다.

### 도구를 어디에 쓰나요?

같은 도구도 앱 유형에 따라 호출 방식이 달라집니다.

| 사용 위치      | 동작 방식                   | 사용 시점               |
| ---------- | ----------------------- | ------------------- |
| **에이전트 앱** | AI가 상황에 맞춰 도구를 호출합니다.   | 도구 선택을 AI에 맡길 때     |
| **워크플로우**  | 정해진 단계에서 도구를 실행합니다.     | 실행 순서와 시점을 통제할 때    |
| **웹사이트 앱** | 코딩 에이전트가 도구를 코드에 구현합니다. | 방문자 동작에 맞춘 기능을 만들 때 |

에이전트 앱에는 [도구 설정하기](../agent/undefined-1/undefined-2.md)를 사용합니다. 웹사이트 앱에는 [플러스(+) 버튼](../website/undefined-1/+.md)에서 도구를 추가합니다.

### 도구 준비 방식

도구 유형에 따라 준비하는 주체가 다릅니다.

| 도구 유형          | 준비 방식                            |
| -------------- | -------------------------------- |
| **기본 도구**      | 관리자가 워크스페이스에 등록하고 활성화합니다.        |
| **워크플로우·에이전트** | 제작자가 도구로 등록하고 발행합니다. 관리자가 승인합니다. |
| **외부 연동**      | 관리자가 API 또는 MCP를 연결하고 활성화합니다.    |

외부 서비스에 접근하는 도구는 인증이 필요할 수 있습니다. 공용 인증은 관리자가 등록합니다. 개인 계정 인증은 사용할 때 연결합니다.

앱은 인증 정보를 저장하지 않습니다. 앱에는 사용할 도구와 입력값만 저장됩니다.

### 문제 해결

도구가 표시되고 실행되려면 다음 조건을 모두 충족해야 합니다.

1. **준비**: 관리자가 도구를 활성화했거나 등록한 도구가 승인되었습니다.
2. **인증**: 공용 인증 정보가 등록됐거나 개인 계정이 연결됐습니다.
3. **선택**: 앱에 도구를 추가했습니다.

{% hint style="info" %}
일부 도구는 실행 전 승인이 필요합니다. 필요한 경우 실행 시 확인 절차가 표시됩니다.
{% endhint %}

문제가 계속되면 활성화와 인증 상태를 관리자에게 확인하세요.
