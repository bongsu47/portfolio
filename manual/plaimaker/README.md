# 플레이메이커

플레이메이커(PLAI MAKER)는 아이디어를 구체화하고 MISO 앱으로 만드는 AI 에이전트 협업 기능입니다.

{% embed url="https://drive.google.com/file/d/1cf33cTyA94b-mSJR4AaqOny4POTdCsQF/view?usp=drive_link" %}

### 전문 에이전트와 함께 만들기

아이디어가 막연해도 괜찮습니다. 전문 에이전트가 문제 정의부터 기획, 앱 제작까지 함께 진행합니다.

<figure><img src="../../.gitbook/assets/team plaimaker2.jpg" alt=""><figcaption></figcaption></figure>

#### Ally: Ideation Coach

아이디어를 구체화하고 핵심 문제와 원인을 정의합니다.

문제 정의에는 목적, 대상 사용자, 핵심 문제, 페인 포인트가 포함됩니다.

#### Kyle: Product Manager

기능을 정리하고 사용자 흐름과 서비스 구조를 설계합니다.

결과물은 PRD(제품 기능 기획서)입니다.

#### Ian: AI Engineer

MISO 앱을 구현합니다.

결과물은 실행할 수 있는 MISO 앱입니다.

#### Heather: UX Designer

Heather는 준비 중입니다.

UX를 설계하고 앱 디자인을 구현합니다.

### 만들 수 있는 앱

플레이메이커는 워크플로우와 에이전트 앱 생성을 지원합니다.

일반 워크플로우, 대화형 워크플로우, 에이전트를 만들 수 있습니다. 생성한 앱은 **앱 리스트**에 등록되며, 필요에 따라 편집할 수 있습니다.

MISO에서 기본으로 지원하지 않는 기능은 구현에 제한이 있을 수 있습니다.
