# 기본 도구

기본 도구는 MISO에서 제공하는 도구입니다. 웹 검색, 이미지 생성, 문서 생성, 데이터 분석에 사용할 수 있습니다.

도구 목록에는 조직 공용 도구와 개인 계정으로 연결하는 도구가 함께 표시됩니다.

<figure><img src="../../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>

#### 도구 공급과 활용

도구를 준비하는 관리자와 앱에 활용하는 제작자의 역할은 다릅니다.

<table><thead><tr><th width="102.3333740234375">구분</th><th width="437.3333740234375">하는 일</th><th>담당</th></tr></thead><tbody><tr><td>도구 공급</td><td>도구 API 연결, 인증정보 등록, 도구 활성화</td><td>관리자</td></tr><tr><td>도구 활용</td><td>공급된 도구를 골라 Agent·워크플로우·웹사이트에 붙여 사용</td><td>제작자 (여러분)</td></tr></tbody></table>

제작자는 관리자가 공급한 도구를 선택해 Agent, 워크플로우, 웹사이트에 추가합니다.

{% hint style="info" %}
도구가 없거나 비활성화되었다면 관리자에게 공급 또는 활성화를 요청하세요.
{% endhint %}
