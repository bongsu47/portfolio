# 도구 이해하기

도구는 AI가 작업을 수행할 때 사용하는 기능입니다. 외부 서비스와 연결하거나, 정보를 검색하고, 콘텐츠를 생성할 수 있습니다.

도구로 다음 작업을 수행할 수 있습니다.

* 실시간 웹 검색과 데이터 분석
* 사내 시스템과 외부 서비스의 데이터 조회·수정
* 이미지·문서 생성과 조직 API 호출

### 도구 유형

**도구 모음**에서 네 가지 유형의 도구를 확인할 수 있습니다.

#### 기본 도구

MISO에서 제공하는 도구입니다. 웹 검색, 이미지·문서 생성, 데이터 분석에 사용합니다.

[basic.md](basic.md "mention")에서 제공 도구와 앱별 활용 방법을 확인합니다.

#### 워크플로우

만든 워크플로우를 하나의 도구처럼 재사용합니다. 다른 앱에서 정해진 순서의 작업을 호출할 때 사용합니다.

[workflow.md](workflow.md "mention")에서 사용 시점과 등록 방법을 확인합니다.

#### 에이전트

만든 에이전트를 다른 에이전트에서 사용할 수 있는 도구로 등록합니다. 여러 전문 에이전트를 조합할 때 사용합니다.

[agent.md](agent.md "mention")에서 등록과 활용 방법을 확인합니다.

#### 외부 연동

관리자가 등록한 커넥터를 사용합니다. 커넥터는 외부 API 또는 MCP 서버와 연결합니다.

본인 계정으로 실행하는 **개인 커넥터**와 공용 인증으로 실행하는 **조직 커넥터**가 있습니다. [connector](connector/ "mention")에서 연결 방법과 권한을 확인합니다.

### 도구를 어디에 쓰나요?

도구의 실행 방식은 앱 유형에 따라 다릅니다.

| 사용 위치      | 실행 방식                   | 적합한 경우              |
| ---------- | ----------------------- | ------------------- |
| **에이전트 앱** | AI가 상황에 맞춰 도구를 호출합니다.   | 도구 선택을 AI에 맡길 때     |
| **워크플로우**  | 정해진 단계에서 도구를 실행합니다.     | 실행 순서와 시점을 제어할 때    |
| **웹사이트 앱** | 코딩 에이전트가 도구를 코드에 구현합니다. | 방문자 동작에 맞춘 기능을 만들 때 |

에이전트 앱에는 [tool.md](../agent/detail/tool.md "mention")를 사용합니다. 웹사이트 앱에서는 [plus-button.md](../website/chat-panel/plus-button.md "mention")으로 도구를 추가합니다.

### 도구 준비 방식

도구 유형에 따라 준비하는 주체와 절차가 다릅니다.

| 도구 유형          | 준비 방식                            |
| -------------- | -------------------------------- |
| **기본 도구**      | 관리자가 워크스페이스에 등록하고 활성화합니다.        |
| **워크플로우·에이전트** | 제작자가 도구로 등록하고 발행합니다. 관리자가 승인합니다. |
| **외부 연동**      | 관리자가 API 또는 MCP 서버를 연결하고 활성화합니다. |

외부 서비스에 접근하는 도구는 인증이 필요할 수 있습니다. 조직 인증은 관리자가 등록합니다. 개인 계정 인증은 처음 사용할 때 연결합니다.

앱은 인증 정보를 저장하지 않습니다. 앱에는 사용할 도구와 입력값만 저장됩니다.

### 문제 해결

도구를 표시하고 실행하려면 다음 조건을 모두 충족해야 합니다.

1. **준비**: 관리자가 도구를 활성화했거나, 등록한 도구가 승인되었습니다.
2. **인증**: 조직 인증 정보를 등록했거나, 개인 계정을 연결했습니다.
3. **추가**: 앱에 도구를 추가했습니다.

{% hint style="info" %}
일부 도구는 실행 전에 승인이 필요합니다. 필요한 경우 실행 중에 승인 요청이 표시됩니다.
{% endhint %}

문제가 계속되면 관리자에게 도구의 활성화와 인증 상태를 확인하세요.
