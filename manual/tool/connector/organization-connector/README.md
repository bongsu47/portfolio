# 조직 커넥터

조직 커넥터는 관리자가 등록한 공용 계정으로 실행되는 커넥터입니다. 관리자가 워크스페이스에 할당하면 계정을 연결하지 않고 바로 사용할 수 있습니다.

개인 커넥터와의 차이와 실행 허용 수준은 [외부 연동](../)에서 확인합니다.

### 커넥터 목록

| 커넥터                         | 할 수 있는 일                                         |
| --------------------------- | ------------------------------------------------ |
| [**CheckyAI**](checkyai.md) | 홍보 이미지의 문구와 시각 요소를 검수하고, 확인이 필요한 영역을 이미지에 표시합니다. |

{% hint style="info" %}
**커넥터가 보이지 않는 경우**

조직 커넥터는 관리자가 할당한 워크스페이스에서만 보입니다. 현재 워크스페이스를 확인하고, 필요하면 관리자에게 할당을 요청합니다.
{% endhint %}
