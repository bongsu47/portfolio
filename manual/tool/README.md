# 도구 모음

## 도구 모음

도구는 AI가 외부 서비스와 연결해 정보를 조회하거나 작업을 수행하는 기능입니다.

도구를 앱에 연결하면 웹 검색, 데이터 조회, 문서 생성, 조직 시스템 호출 같은 작업을 수행할 수 있습니다.

### 도구 유형

도구 선택 화면에서는 다음 유형을 제공합니다.

* **기본 도구**: MISO가 제공하는 웹 검색, 이미지 생성, 문서 생성, 데이터 분석 도구입니다.
* **워크플로우**: 만든 워크플로우를 다른 앱에서 도구처럼 재사용합니다.
* **에이전트:** 만든 에이전트를 Orchestrator 에이전트에서 사용합니다.
* **외부 연동**: 관리자가 연결한 커스텀 API와 MCP 서버를 사용합니다.
