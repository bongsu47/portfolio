# 템플릿으로 시작하기

<figure><img src="../../.gitbook/assets/스크린샷 2026-07-28 164241.png" alt=""><figcaption></figcaption></figure>

템플릿을 선택하면 미리 구성된 앱을 빠르게 만들 수 있습니다.

### 템플릿 찾기

* 내 소속 고객사에 맞는 템플릿과 공통 템플릿만 표시됩니다.
* 검색창에서 앱 이름으로 템플릿을 찾습니다.
* 지식이 포함된 템플릿에는 **지식** 배지가 표시됩니다.

### 생성 전 확인 사항

템플릿을 만들 때 워크스페이스 환경에 맞춰 도구와 모델을 확인하고 적용합니다.

#### 도구

템플릿에 활성화되지 않은 도구가 포함되면 앱을 만들 수 없습니다.

생성 버튼이 비활성화되고 도구를 활성화한 뒤 다시 시도하라는 안내가 표시됩니다. 관리자에게 도구 활성화를 요청합니다.

#### LLM 모델

사용 가능한 LLM이 없으면 앱을 만들 수 없습니다. 관리자는 **모델 관리**에서 LLM을 활성화해야 합니다.

템플릿에 지정된 LLM이 없으면 **워크스페이스 기본 모델 → 고객사 기본 모델** 순서로 대체합니다.

#### 지식 임베딩 모델

지식(샘플 문서)이 포함된 템플릿에는 임베딩 모델이 필요합니다.

임베딩 모델이 없으면 안내가 표시되며 앱을 만들 수 없습니다. 모델이 있으면 **워크스페이스 기본 → 고객사 기본** 순서로 적용합니다.

지식이 없는 템플릿은 임베딩 모델 없이도 만들 수 있습니다.

#### 리랭킹 모델

템플릿에 지정된 리랭킹 모델이 있으면 해당 모델을 사용합니다.

모델이 없으면 리랭킹을 끄고 앱을 만듭니다. 검색 품질에는 영향을 줄 수 있습니다.

### 지식이 포함된 템플릿

지식(샘플 문서)이 포함된 템플릿을 만들면 샘플 문서가 내 데이터셋에 자동으로 임베딩됩니다.

* 임베딩 진행 상태가 화면에 표시됩니다. 완료되면 앱의 지식으로 연결됩니다.
* 같은 템플릿으로 앱을 다시 만들면 이미 임베딩된 지식을 재사용합니다.

<figure><img src="../../.gitbook/assets/스크린샷 2026-07-28 164943.png" alt=""><figcaption></figcaption></figure>

### 자주 묻는 질문

#### 지식 임베딩이 오래 걸립니다.

샘플 문서의 크기와 수에 따라 임베딩 시간이 달라집니다.

진행 상태가 표시되며, 완료 후 앱에서 지식을 사용할 수 있습니다.

#### 템플릿으로 만든 앱을 수정할 수 있나요?

생성된 앱은 일반 앱과 동일하게 편집하고 발행할 수 있습니다.
