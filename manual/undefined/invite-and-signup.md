# 초대장 및 회원 가입

## 사용자 초대하기

MISO를 처음 사용하려면 이메일 초대장을 받아 회원 가입해야 합니다.

사용자를 관리할 권한이 있는 사용자는 이메일로 새 사용자를 초대합니다.

{% stepper %}
{% step %}
#### 사용자 설정 열기

화면의 사용자 이름을 선택한 뒤 **사용자 설정**을 선택합니다.

<figure><img src="../../.gitbook/assets/스크린샷 2026-06-19 183430.png" alt=""><figcaption><p>사용자 이름 → 사용자 설정</p></figcaption></figure>
{% endstep %}

{% step %}
#### 사용자 초대 선택하기

**사용자 관리**에서 **사용자 초대**를 선택합니다.

<figure><img src="../../.gitbook/assets/사용자 초대.png" alt=""><figcaption><p>사용자 관리 → 사용자 초대</p></figcaption></figure>
{% endstep %}

{% step %}
#### 초대 이메일 보내기

초대할 사용자의 이메일 주소를 입력한 뒤 초대를 보냅니다.

<figure><img src="../../.gitbook/assets/image (146).png" alt=""><figcaption><p>사용자 초대</p></figcaption></figure>
{% endstep %}
{% endstepper %}

### 초대 이메일 확인하기

초대받은 사용자는 MISO 초대 이메일을 받습니다.

<figure><img src="../../.gitbook/assets/image (283).png" alt=""><figcaption><p>&#x3C;MISO 초대장></p></figcaption></figure>

### 회원 가입하기

{% stepper %}
{% step %}
#### 가입 화면 열기

초대 이메일에서 **미소 가입하기**를 선택합니다.

<figure><img src="../../.gitbook/assets/image (284).png" alt=""><figcaption><p>&#x3C;MISO 회원가입 화면></p></figcaption></figure>
{% endstep %}

{% step %}
#### 가입 완료하기

MISO에서 사용할 이름과 비밀번호를 입력합니다.

비밀번호 확인을 입력한 뒤 **가입하기**를 선택하면 회원 가입이 완료됩니다.
{% endstep %}
{% endstepper %}
