# 로그인과 비밀번호 재설정

### 로그인하기

MISO는 이메일과 비밀번호로 로그인합니다.\
조직 정책에 따라 Microsoft 계정 로그인을 제공할 수 있습니다.

{% stepper %}
{% step %}
#### 계정 정보 입력하기

로그인 화면에서 이메일과 비밀번호를 입력합니다.

<figure><img src="../../.gitbook/assets/image (184).png" alt=""><figcaption><p>MISO 로그인 화면</p></figcaption></figure>
{% endstep %}

{% step %}
#### 미소AI 열기

인증이 완료되면 미소AI 화면으로 이동합니다.

장시간 미사용 후에는 다시 로그인해야 할 수 있습니다.

<figure><img src="../../.gitbook/assets/image (311).png" alt=""><figcaption><p>미소AI 화면</p></figcaption></figure>
{% endstep %}
{% endstepper %}

### 비밀번호 재설정하기

비밀번호를 잊었다면 이메일 인증으로 새 비밀번호를 설정합니다.

{% stepper %}
{% step %}
#### 재설정 요청하기

비밀번호 재설정 화면에서 가입한 이메일 주소를 입력합니다.

<figure><img src="../../.gitbook/assets/image (185).png" alt=""><figcaption><p>비밀번호 재설정 화면</p></figcaption></figure>
{% endstep %}

{% step %}
#### 이메일 확인하기

입력한 이메일 주소로 비밀번호 재설정 안내 메일이 발송됩니다.

<figure><img src="../../.gitbook/assets/image (186).png" alt=""><figcaption><p>비밀번호 재설정 이메일</p></figcaption></figure>
{% endstep %}

{% step %}
#### 새 비밀번호 설정하기

이메일에서 **비밀번호 변경하기**를 선택합니다.

새 비밀번호를 입력하고 변경을 완료합니다.

<figure><img src="../../.gitbook/assets/image (187).png" alt=""><figcaption><p>비밀번호 변경 화면</p></figcaption></figure>

<figure><img src="../../.gitbook/assets/image (188).png" alt=""><figcaption><p>비밀번호 변경 완료 화면</p></figcaption></figure>
{% endstep %}

{% step %}
#### 다시 로그인하기

**로그인 하기**를 선택한 뒤 새 비밀번호로 로그인합니다.
{% endstep %}
{% endstepper %}
