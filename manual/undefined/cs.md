# 미소 CS봇

### CS봇 열기

화면 오른쪽 아래의 **CS봇** 버튼을 선택하면 창이 열립니다.

버튼은 드래그하여 원하는 위치로 옮길 수 있습니다. 변경한 위치는 저장됩니다.

CS봇은 MISO의 모든 페이지에서 사용할 수 있습니다.

<div align="center"><figure><img src="../../.gitbook/assets/CS봇 위젯.png" alt="" width="563"><figcaption></figcaption></figure></div>

### 질문하기

{% stepper %}
{% step %}
#### 질문 입력하기

**질문하기** 탭에 궁금한 내용을 입력한 뒤 전송합니다.
{% endstep %}

{% step %}
#### 답변 확인하기

AI가 실시간으로 답변합니다. 답변 뒤에 추가 질문을 이어서 보낼 수 있습니다.
{% endstep %}

{% step %}
#### 파일과 피드백 추가하기

화면 캡처 등 파일을 첨부할 수 있습니다.

답변 아래의 👍 또는 👎로 피드백을 남기면 답변 품질 개선에 반영됩니다.
{% endstep %}
{% endstepper %}

<div align="center"><figure><img src="../../.gitbook/assets/image (758).png" alt="" width="375"><figcaption></figcaption></figure></div>

{% hint style="info" %}
질문은 구체적으로 적을수록 정확한 답을 받습니다.
{% endhint %}

### 이슈 등록하기

질문으로 해결되지 않은 오류나 개선 요청은 **이슈 등록** 탭에서 접수합니다.

{% stepper %}
{% step %}
#### 유형 선택하기

**버그 및 오류**, **UX 개선**, **기능 추가** 중 유형을 선택합니다.
{% endstep %}

{% step %}
#### 이슈 작성하기

제목과 상세 설명을 입력합니다.

재현 방법과 기대 동작을 함께 작성하면 검토에 도움이 됩니다.
{% endstep %}

{% step %}
#### 첨부하고 등록하기

필요하면 화면 캡처나 파일을 첨부합니다.

등록한 이슈는 MISO 운영팀에 자동 전달됩니다.
{% endstep %}
{% endstepper %}

<div align="center"><figure><img src="../../.gitbook/assets/image (759).png" alt="" width="375"><figcaption></figcaption></figure></div>

{% hint style="info" %}
이슈 한 건에는 한 가지 내용만 작성합니다. 여러 이슈는 각각 등록하면 추적하기 쉽습니다.
{% endhint %}

### 참고 사항

* 대화 기록은 CS봇 위젯에서 다시 확인할 수 있습니다.
* 민감한 개인정보는 입력하지 않습니다.
* 담당팀은 등록한 이슈를 검토한 뒤 처리합니다. 처리에는 시간이 걸릴 수 있습니다.
