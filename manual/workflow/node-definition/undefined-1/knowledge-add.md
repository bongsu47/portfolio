# 지식 추가

지식 추가 노드는 워크플로우 실행 중 지식에 새 내용을 추가합니다.\
생성한 텍스트나 업로드한 파일을 저장하고, 이후 검색에 활용할 수 있습니다.

<figure><img src="../../../../.gitbook/assets/image (40).png" alt="" width="290"><figcaption></figcaption></figure>

### 역할

워크플로우 실행 중에 지식을 동적으로 추가합니다.\
고정된 지식뿐 아니라 대화와 실행 결과를 계속 누적할 수 있습니다.

다음과 같은 작업에 사용할 수 있습니다.

* 상담 요약을 저장하고 다음 상담의 참고 자료로 활용
* 사용자가 업로드한 문서를 자동 등록
* 매일 수집한 데이터를 하나의 지식에 누적

추가한 내용은 인덱싱이 완료되면 지식 검색에서 사용할 수 있습니다.

### 사용 시점

워크플로우에서 지식을 자동으로 축적해야 할 때 사용합니다.

* 대화 결과나 AI 생성 내용을 저장할 때
* 업로드한 파일을 자동 등록할 때
* 반복 실행 결과를 하나의 지식에 누적할 때

{% hint style="info" %}
**지식 추가와 지식 검색**

지식 검색은 등록한 지식에서 정보를 찾습니다.\
지식 추가는 새 정보를 지식에 저장합니다.\
두 노드를 함께 사용하면 정보를 축적하고 활용할 수 있습니다.
{% endhint %}

### 설정

지식 추가 노드를 선택하면 설정 패널이 열립니다.\
패널은 **입력 변수**와 **도구 설정**으로 나뉩니다.

<figure><img src="../../../../.gitbook/assets/image (41).png" alt="" width="325"><figcaption></figcaption></figure>

#### 입력 변수

워크플로우에서 전달한 값을 설정합니다.\
직접 텍스트를 입력하거나 `/`로 이전 노드 변수를 선택합니다.

**지식 이름**

추가할 지식의 이름입니다.\
기존 지식을 선택하지 않으면 이 이름으로 새 지식을 생성합니다.

변수를 연결하면 실행마다 다른 이름의 지식을 만들 수 있습니다.

**지식 설명**

새로 생성할 지식의 설명입니다.\
기존 지식을 선택한 경우에는 사용하지 않습니다.

**텍스트 콘텐츠**

지식에 추가할 텍스트입니다.\
LLM 요약이나 코드 노드 출력은 변수로 연결하는 방식이 일반적입니다.

직접 입력하거나 텍스트와 변수를 함께 사용할 수 있습니다.

**콘텐츠 파일명**

텍스트 콘텐츠를 저장할 파일명입니다.\
입력하지 않으면 `content.txt`로 저장됩니다.\
`.txt` 확장자는 생략할 수 있습니다.

**기존 문서에 추가**를 사용하면 파일명이 기준이 됩니다.\
같은 파일명의 문서를 찾아 내용을 이어 붙입니다.

**기존 문서에 추가**

활성화하면 같은 파일명의 기존 문서에 내용을 이어 붙입니다.\
새 문서를 만들지 않습니다.

|              | 토글 꺼짐 (기본)        | 토글 켜짐                       |
| ------------ | ----------------- | --------------------------- |
| 동작           | 항상 새 문서로 추가       | 같은 파일명의 문서가 있으면 해당 문서에 이어붙임 |
| 같은 파일명이 있을 때 | 동일한 이름의 문서가 2개 생김 | 기존 문서에 내용 추가                |
| 같은 파일명이 없을 때 | 새 문서 생성           | 새 문서 생성 (토글 꺼짐과 동일)         |

반복 실행 결과를 하나의 문서에 누적할 때 사용하세요.

#### 도구 설정

노드의 기본 동작을 설정합니다.

**지식 선택**

내용을 추가할 기존 지식을 선택합니다.\
워크스페이스에 등록한 지식 목록이 표시됩니다.

* 기존 지식을 선택하면 해당 지식에 문서를 추가합니다.
* 선택하지 않으면 입력 변수의 지식 이름으로 새 지식을 생성합니다.

**지식 이름**

기존 지식을 선택하지 않으면 표시됩니다.\
새 지식의 이름을 지정하거나 `/`로 변수를 선택합니다.

**파일**

지식에 추가할 파일 변수를 선택합니다.\
시작 노드의 파일 입력이나 이전 노드의 파일 결과를 연결합니다.

텍스트 콘텐츠와 파일을 함께 사용할 수 있습니다.\
둘 다 입력하면 텍스트와 파일을 모두 추가합니다.

#### 기존 지식 추가와 새 지식 생성

|        | 기존 지식에 추가                | 새 지식 생성                       |
| ------ | ------------------------ | ----------------------------- |
| 설정 방법  | 도구 설정 > 지식 선택에서 기존 지식 선택 | 지식 선택을 비워두고, 입력 변수 > 지식 이름 입력 |
| 적합한 경우 | 고정된 하나의 지식에 계속 내용을 쌓을 때  | 실행할 때마다 새로운 지식을 만들어야 할 때      |
| 예시     | 상담 기록을 하나의 지식에 누적        | 고객별로 별도의 지식 생성                |

#### 텍스트 콘텐츠와 파일 비교

|        | 텍스트 콘텐츠                   | 파일                            |
| ------ | ------------------------- | ----------------------------- |
| 입력 위치  | 입력 변수 영역                  | 도구 설정 영역                      |
| 사용 상황  | LLM이 생성한 텍스트, 코드 노드의 결과 등 | 사용자가 업로드한 파일, 외부에서 받아온 파일     |
| 저장 형식  | .txt 파일로 변환되어 저장          | 원본 파일 형식 그대로 저장 (PDF, DOCX 등) |
| 적합한 경우 | 워크플로우 내에서 만들어진 텍스트를 저장할 때 | 파일 자체를 지식에 등록할 때              |

둘 중 하나 또는 둘 다 입력할 수 있습니다.\
둘 다 비어 있으면 노드는 실행을 건너뜁니다.

### 출력 변수

| 변수             | 타입     | 설명            |
| -------------- | ------ | ------------- |
| `status`       | String | 처리 상태         |
| `dataset_id`   | String | 지식의 고유 ID     |
| `dataset_name` | String | 지식 이름         |
| `document_ids` | Array  | 추가된 문서의 ID 목록 |
| `message`      | String | 처리 결과 메시지     |

`status`는 다음 값 중 하나를 반환합니다.

| 상태           | 의미                                        |
| ------------ | ----------------------------------------- |
| `processing` | 새 문서가 추가되었고, 인덱싱이 진행 중입니다                 |
| `completed`  | 기존 문서에 내용이 추가 완료되었습니다 (기존 문서에 추가 옵션 사용 시) |
| `skipped`    | 텍스트 콘텐츠와 파일이 모두 비어있어 실행을 건너뛰었습니다          |

{% hint style="warning" %}
**인덱싱 완료 후 검색 가능**

새 문서를 추가하면 인덱싱 완료 전까지 검색 결과에 나타나지 않습니다.\
소요 시간은 문서 크기에 따라 다릅니다.\
인덱싱 상태는 **인덱싱 상태 확인** 노드에서 확인하세요.

기존 문서에 추가한 경우(`completed`)에는 즉시 검색할 수 있습니다.
{% endhint %}
