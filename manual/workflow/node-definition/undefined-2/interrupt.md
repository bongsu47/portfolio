# 인터럽트

{% hint style="warning" %}
**사용 전 확인**

* **실험실 기능**: 관리자가 기능을 활성화해야 합니다.
* **챗플로우 전용**: 일반 워크플로우에서는 노드 목록에 표시되지 않습니다.
{% endhint %}

인터럽트 노드는 워크플로우를 일시 정지합니다.\
사용자 입력을 받으면 실행을 다시 시작합니다.

<figure><img src="../../../../.gitbook/assets/image (23).png" alt="" width="296"><figcaption></figcaption></figure>

사람의 판단이나 추가 정보가 필요한 단계에서 사용합니다.

### 역할

워크플로우 중간에 사용자에게 질문하거나 선택을 요청합니다.

<figure><img src="../../../../.gitbook/assets/image (22).png" alt="" width="441"><figcaption></figcaption></figure>

다음과 같은 작업에 사용할 수 있습니다.

* LLM 초안을 보여주고 승인 또는 거절을 받습니다.
* 폼 입력으로 추가 정보를 요청합니다.
* 분기 선택으로 사용자가 실행 경로를 결정합니다.

조건 노드는 규칙으로 자동 분기합니다.\
인터럽트 노드는 사용자 판단에 따라 분기합니다.

{% hint style="info" %}
**인터럽트와 조건 노드**

* **인터럽트**: 실행을 멈추고 사용자 응답을 기다립니다.
* **조건**: 변수 값을 비교해 자동으로 분기합니다.

승인, 사용자 확인, 추가 정보 입력에 인터럽트를 사용하세요.
{% endhint %}

### 인터럽트 유형

설정 패널에서 세 가지 유형 중 하나를 선택합니다.

#### 승인

<figure><img src="../../../../.gitbook/assets/image (24).png" alt="" width="563"><figcaption></figcaption></figure>

사용자에게 승인 또는 거절을 요청합니다.

* 채팅 화면에 승인과 거절 버튼이 표시됩니다.
* 응답에 따라 승인 또는 거절 경로로 실행합니다.
* 캔버스의 각 출력 핸들에 다른 노드를 연결할 수 있습니다.

| 출력 변수      | 타입      | 설명                 |
| ---------- | ------- | ------------------ |
| `approved` | Boolean | 승인 여부 (true/false) |
| `comment`  | String  | 사용자가 남긴 코멘트 (선택)   |

#### 폼 입력

<figure><img src="../../../../.gitbook/assets/image (25).png" alt="" width="563"><figcaption></figcaption></figure>

사용자에게 폼을 표시하고 데이터를 입력받습니다.

* 필드를 추가하고 변수명, 타입, 필수 여부를 지정합니다.
* 실행이 멈추면 채팅 화면에 폼이 표시됩니다.
* 사용자가 제출하면 워크플로우를 재개합니다.

**지원 필드 타입**

| 타입     | 설명           | 입력 UI     |
| ------ | ------------ | --------- |
| 텍스트    | 한 줄 텍스트      | 텍스트 입력란   |
| 텍스트 영역 | 여러 줄 텍스트     | 텍스트 영역    |
| 숫자     | 숫자 값         | 숫자 입력란    |
| 참/거짓   | Boolean 값    | 토글 탭      |
| 단일 선택  | 옵션 중 하나 선택   | 라디오/드롭다운  |
| 다중 선택  | 옵션 중 여러 개 선택 | 체크박스/콤보박스 |

각 필드에 변수명, 라벨, 설명, 필수 여부를 설정합니다.\
단일 선택과 다중 선택에는 옵션 목록도 설정합니다.

#### 분기 선택

<figure><img src="../../../../.gitbook/assets/image (26).png" alt=""><figcaption></figcaption></figure>

사용자에게 여러 선택지를 보여주고 하나를 선택하게 합니다.

* 설정 패널에서 분기 옵션을 두 개 이상 추가합니다.
* 각 옵션에 라벨을 지정합니다.
* 채팅 화면에서 선택하면 해당 경로로 실행합니다.
* 각 출력 핸들에 다른 노드를 연결할 수 있습니다.

| 출력 변수             | 타입     | 설명         |
| ----------------- | ------ | ---------- |
| `selected_branch` | String | 선택된 분기의 ID |

### 설정

<figure><img src="../../../../.gitbook/assets/image (27).png" alt="" width="458"><figcaption></figcaption></figure>

#### 인터럽트 유형

설정 패널 상단에서 **승인**, **폼 입력**, **분기 선택**을 선택합니다.

{% hint style="warning" %}
유형을 변경하면 노드에서 나가는 연결선이 제거됩니다.\
유형마다 출력 핸들 구조가 다르기 때문입니다.
{% endhint %}

#### 안내 메시지

실행이 멈출 때 사용자에게 표시할 메시지를 입력합니다.

예: “아래 내용을 확인하고 승인 또는 거절해 주세요.”

안내 메시지에 변수를 삽입할 수 있습니다.\
`{{#노드ID.변수명#}}` 형식으로 이전 노드의 출력값을 참조합니다.

#### 폼 필드

폼 입력 유형을 선택하면 설정할 수 있습니다.

* `+`를 선택해 필드를 추가합니다.
* 변수명, 라벨, 설명을 입력합니다. 변수명에는 영문, 숫자, 밑줄만 사용합니다.
* 타입과 필수 여부를 설정합니다.
* 선택 필드에는 옵션 목록을 추가합니다. 옵션은 최대 50자입니다.

#### 분기 옵션

분기 선택 유형을 선택하면 설정할 수 있습니다.

* `+`를 선택해 분기를 추가합니다.
* 각 분기에 라벨을 입력합니다.
* 분기를 삭제하면 연결선도 제거됩니다.

#### 타임아웃

사용자 응답을 기다릴 최대 시간을 설정합니다.

| 설정   | 범위                  | 기본값    |
| ---- | ------------------- | ------ |
| 타임아웃 | 1분 \~ 1,440분 (24시간) | 1,440분 |

타임아웃이 지나면 워크플로우는 **실패** 상태로 종료됩니다.\
슬라이더 또는 직접 입력으로 조절합니다.

### 출력 변수

| 변수                    | 타입     | 설명          |
| --------------------- | ------ | ----------- |
| `__interrupt_input__` | Object | 사용자의 응답 데이터 |

응답 데이터 구조는 인터럽트 유형에 따라 달라집니다.

* **승인**: `{ approved: true/false, comment: "..." }`
* **폼 입력**: `{ 변수명1: 값1, 변수명2: 값2, ... }`
* **분기 선택**: `{ selected_branch: "선택된_분기_ID" }`

이후 노드에서 `__interrupt_input__`으로 사용자 응답을 참조합니다.

### 제한 사항

| 제한            | 설명                                                   |
| ------------- | ---------------------------------------------------- |
| 챗플로우 전용       | 일반 워크플로우(Completion 모드)에서는 사용할 수 없습니다                |
| 루프/반복 내 사용 불가 | 반복(Iteration) 노드나 루프(Loop) 노드 안에 배치할 수 없습니다          |
| 타임아웃          | 설정한 시간 내에 응답하지 않으면 워크플로우가 실패합니다                      |
| 일시 정지 중 수정    | 워크플로우가 일시 정지된 상태에서 그래프를 수정해도 재개 시에는 정지 시점의 상태로 실행됩니다 |
| 병렬 분기         | 병렬로 실행되는 분기 안에 인터럽트가 있으면 모든 분기가 함께 멈춥니다              |
