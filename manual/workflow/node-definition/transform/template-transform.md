# 템플릿

템플릿 노드는 여러 변수를 조합해 텍스트를 만듭니다.

<figure><img src="../../../../.gitbook/assets/image (13).png" alt="" width="297"><figcaption></figcaption></figure>

미리 작성한 틀에 변수 값을 넣어 텍스트를 완성합니다.\
이메일 제목, 검색 결과, LLM 프롬프트를 구성할 때 사용합니다.

{% hint style="info" %}
**템플릿, 코드, LLM 노드 비교**

* **템플릿 노드**: 변수를 조합해 텍스트를 만듭니다.
* **코드 노드**: 계산, 데이터 변환, 복잡한 로직에 사용합니다.
* **LLM 노드**: 내용을 이해하고 새 텍스트를 생성합니다.

변수를 조합하거나 형식을 지정할 때는 템플릿 노드를 사용하세요.
{% endhint %}

### 역할

다음과 같은 작업에 사용할 수 있습니다.

* 지식 검색 결과를 정리해 LLM에 전달합니다.
* 사용자 정보와 문의 내용을 조합해 응대 메시지를 만듭니다.
* 조건에 따라 다른 프롬프트를 구성합니다.

LLM을 호출하지 않아 비용이 없고 결과가 일관됩니다.

### 설정

<figure><img src="../../../../.gitbook/assets/image (14).png" alt="" width="368"><figcaption></figcaption></figure>

#### 입력 변수

템플릿에서 사용할 변수를 추가합니다.\
**추가**를 선택해 변수 이름을 지정하고 이전 노드의 값을 연결합니다.

예를 들어 사용자 입력은 `query`, 검색 결과는 `results`로 추가합니다.

#### 템플릿 작성

틀이 되는 텍스트를 작성합니다.\
변수 위치에는 `{{ 변수이름 }}`을 입력합니다.

```
안녕하세요, {{ name }}님!
오늘 문의하신 내용은 "{{ query }}" 입니다.
```

`name`이 “홍길동”이고 `query`가 “환불 방법”이면 다음 결과를 반환합니다.

```
안녕하세요, 홍길동님!
오늘 문의하신 내용은 "환불 방법" 입니다.
```

{% hint style="info" %}
**변수 삽입**

편집기에서 `{{` 또는 `/`를 입력하면 변수 목록이 표시됩니다.\
변수를 선택하면 자동으로 삽입합니다.
{% endhint %}

### 자주 쓰는 문법

#### 조건에 따라 다른 내용 표시

`{% if %}`와 `{% endif %}`로 조건에 따라 다른 내용을 표시합니다.

```
{% if results | length > 0 %}
검색 결과가 {{ results | length }}건 있습니다.
{% else %}
검색 결과가 없습니다. 다른 키워드로 시도해보세요.
{% endif %}
```

한 줄 조건문도 사용할 수 있습니다.

```
상태: {{ "VIP 고객" if is_vip else "일반 고객" }}
```

#### 목록 반복

`{% for %}`와 `{% endfor %}`로 배열 항목을 순서대로 출력합니다.

```
{% for item in results %}
{{ loop.index }}. {{ item.title }}
{% endfor %}
```

결과는 다음과 같습니다.

```
1. 환불 정책 안내
2. 반품 절차 가이드
3. 교환 방법
```

배열이 비어 있으면 대체 텍스트를 표시할 수 있습니다.

```
{% for item in results %}
- {{ item.title }}
{% else %}
검색 결과가 없습니다.
{% endfor %}
```

#### 필터로 값 변환

`|` 뒤에 필터를 추가해 값을 변환합니다.

| 필터                | 설명           | 예시                                | 결과                 |
| ----------------- | ------------ | --------------------------------- | ------------------ |
| `default`         | 빈 값일 때 기본값   | `{{ name \| default("미입력") }}`    | `미입력`              |
| `length`          | 항목 수         | `{{ items \| length }}`           | `3`                |
| `join`            | 배열을 하나로 합치기  | `{{ items \| join(", ") }}`       | `사과, 바나나, 오렌지`     |
| `truncate`        | 길이 제한        | `{{ text \| truncate(50) }}`      | `긴 텍스트를 50자까지만...` |
| `upper` / `lower` | 대/소문자 변환     | `{{ "hello" \| upper }}`          | `HELLO`            |
| `replace`         | 텍스트 치환       | `{{ text \| replace("A", "B") }}` | A를 B로 치환           |
| `round`           | 반올림          | `{{ 3.1415 \| round(2) }}`        | `3.14`             |
| `tojson`          | JSON 문자열로 변환 | `{{ data \| tojson }}`            | `{"key": "value"}` |

필터는 여러 개 연결할 수 있습니다.

```
{{ results | map(attribute="title") | join(", ") }}
```

결과: `환불 정책 안내, 반품 절차 가이드, 교환 방법`

#### 객체 값 참조

여러 속성을 가진 객체는 점(`.`)으로 값을 참조합니다.

```
이름: {{ user.name }}
이메일: {{ user.email }}
```

### 활용 예시

#### 지식 검색 결과를 LLM에 전달

지식 검색 결과를 정리해 LLM에 전달합니다.

```
아래 자료를 참고하여 사용자의 질문에 답변해주세요.

사용자 질문: {{ query }}

{% for doc in results %}
---
[참고자료 {{ loop.index }}] {{ doc.title }}
{{ doc.content }}
{% endfor %}
```

#### 조건에 따라 다른 프롬프트 구성

사용자 상황에 따라 LLM 지시문을 다르게 구성합니다.

```
{% if category == "환불" %}
고객이 환불을 요청했습니다. 환불 정책에 맞게 안내해주세요.
{% elif category == "배송" %}
고객이 배송에 대해 문의했습니다. 배송 현황을 안내해주세요.
{% else %}
고객 문의에 친절하게 응대해주세요.
{% endif %}

고객 메시지: {{ message }}
```

#### 고객 응대 메시지 생성

변수를 조합해 일관된 응대 메시지를 만듭니다.

```
{{ name | default("고객") }}님, 안녕하세요.

문의하신 "{{ query }}" 건에 대해 안내드립니다.

{{ answer }}

추가 궁금한 점이 있으시면 언제든 문의해주세요.
감사합니다.
```

#### 검색 결과를 번호 목록으로 정리

```
총 {{ results | length }}건의 결과를 찾았습니다.

{% for item in results %}
{{ loop.index }}. {{ item.title }}
   - {{ item.content | truncate(100) }}
{% else %}
관련 자료를 찾지 못했습니다.
{% endfor %}
```

#### HTML 응답 생성

표, 목록, 링크를 포함한 HTML 응답을 만들 수 있습니다.

```
<h2>{{ query }}에 대한 검색 결과</h2>

<table>
  <tr>
    <th>번호</th>
    <th>제목</th>
    <th>내용</th>
  </tr>
  {% for item in results %}
  <tr>
    <td>{{ loop.index }}</td>
    <td>{{ item.title }}</td>
    <td>{{ item.content | truncate(80) }}</td>
  </tr>
  {% endfor %}
</table>

{% if results | length == 0 %}
<p>검색 결과가 없습니다.</p>
{% endif %}
```

링크와 강조 표시도 추가할 수 있습니다.

```
<p>안녕하세요, <strong>{{ name | default("고객") }}</strong>님.</p>

<ul>
  {% for item in items %}
  <li>{{ item.title }} — {{ item.description }}</li>
  {% endfor %}
</ul>

<p>자세한 내용은 <a href="{{ link }}">여기</a>를 참고해주세요.</p>
```

#### 빈 값에 기본값 설정

기본값을 설정하면 빈 값 없이 결과를 만들 수 있습니다.

```
이름: {{ name | default("미입력") }}
부서: {{ department | default("소속 없음") }}
연락처: {{ phone | default("등록된 연락처 없음") }}
```

### 출력 변수

| 변수       | 설명               |
| -------- | ---------------- |
| `output` | 템플릿으로 생성한 최종 텍스트 |

{% hint style="info" %}
**참고 사항**

* 출력 텍스트는 최대 **80,000자**입니다. 초과하면 오류가 발생합니다.
* 변수가 없을 때는 `| default("")`로 오류를 방지하세요.
* 변수 하나만 전달하면 직접 참조하는 편이 더 간단합니다.
* 계산이나 복잡한 로직에는 코드 노드를 사용하세요.
{% endhint %}
