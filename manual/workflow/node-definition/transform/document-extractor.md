# 문서 추출기

문서 추출기 노드는 업로드한 문서 파일에서 텍스트를 추출합니다.

<figure><img src="../../../../.gitbook/assets/image (11) (1).png" alt="" width="293"><figcaption></figcaption></figure>

LLM은 PDF나 Word 파일 자체가 아닌 텍스트 내용을 처리합니다.\
문서 추출기는 파일을 LLM이 처리할 수 있는 텍스트로 변환합니다.

### 역할

파일 내용을 읽고 텍스트로 변환합니다.

다음과 같은 작업에 사용할 수 있습니다.

* PDF 보고서에서 텍스트를 추출합니다.
* Excel 파일의 표를 마크다운 테이블로 변환합니다.

추출한 텍스트는 LLM 노드에서 분석하거나 코드 노드에서 가공할 수 있습니다.

{% hint style="info" %}
**문서 추출기와 지식**

* **문서 추출기**: 실행 중 업로드한 파일에서 즉시 텍스트를 추출합니다.
* **지식**: 미리 등록하고 인덱싱한 문서를 반복 검색합니다.

매번 다른 파일을 분석하면 문서 추출기를 사용하세요.\
고정된 참고 자료를 반복 검색하면 지식을 사용하세요.
{% endhint %}

### 설정

<figure><img src="../../../../.gitbook/assets/image (12) (1).png" alt="" width="368"><figcaption></figcaption></figure>

#### 입력 파일

텍스트를 추출할 파일 변수를 선택합니다.\
단일 파일과 파일 배열을 모두 사용할 수 있습니다.

일반적으로 시작 노드의 파일 입력 또는 `sys.files`를 선택합니다.

#### 원본 형식 유지

문서에 포함된 HTML 서식을 유지할지 선택합니다.

| 설정        | 동작                                            |
| --------- | --------------------------------------------- |
| 비활성화 (기본) | HTML 태그를 제거하고 깨끗한 텍스트만 추출합니다                  |
| 활성화       | HTML 서식(`<b>`, `<table>`, `<a>` 등)을 그대로 유지합니다 |

HTML 파일에 다음 내용이 있다고 가정합니다.

```html
<h1>공지사항</h1>
<p>다음 주 <b>월요일</b>에 회의가 있습니다.</p>
<a href="https://example.com">참고 링크</a>
```

* **비활성화**: `공지사항 다음 주 월요일에 회의가 있습니다. 참고 링크`
* **활성화**: HTML 태그를 포함한 원본을 추출합니다.

일반적으로 기본값인 비활성화를 사용하세요.\
HTML 구조를 분석하거나 그대로 표시할 때만 활성화합니다.

### 지원 파일 형식

| 분류     | 형식                       | 추출 결과                              |
| ------ | ------------------------ | ---------------------------------- |
| 문서     | PDF                      | 페이지별로 구분된 텍스트 (`--- Page 1 ---` 등) |
|        | Word (.docx)             | 문단 텍스트 + 표는 마크다운 테이블로 변환           |
|        | PowerPoint (.pptx)       | 슬라이드 내 텍스트와 표 내용                   |
| 스프레드시트 | Excel (.xlsx)            | 시트별로 구분된 마크다운 테이블                  |
|        | CSV                      | 마크다운 테이블 형태                        |
| 텍스트    | TXT, Markdown, HTML, XML | 원본 텍스트 그대로                         |
| 데이터    | JSON                     | 보기 좋게 정렬된 JSON                     |
|        | YAML                     | 구조 유지한 텍스트                         |
| 이메일    | EML, MSG                 | 제목, 발신자/수신자/참조/숨은참조, 본문            |
| 전자책    | EPUB                     | 챕터별 텍스트                            |
| 자막     | VTT                      | 자막 텍스트                             |

{% hint style="info" %}
**지원하지 않는 형식**

* PowerPoint `.ppt`는 지원하지 않습니다. `.pptx`로 변환해 사용하세요.
* 비밀번호를 설정한 파일은 추출할 수 없습니다.
* Word `.doc`와 Excel `.xls`보다 `.docx`, `.xlsx`를 권장합니다.
{% endhint %}

### 표와 이미지 추출

회의록처럼 텍스트 중심 문서는 단순 추출로 처리할 수 있습니다.

Word와 Excel 표는 마크다운 테이블로 변환합니다.\
이미지와 이미지 안의 텍스트는 추출하지 않습니다.

복잡한 레이아웃 문서는 요소별로 적절한 처리가 필요합니다.

### 출력 변수

| 변수     | 설명                                            |
| ------ | --------------------------------------------- |
| `text` | 추출된 텍스트. 단일 파일 입력 시 텍스트 하나, 여러 파일 입력 시 텍스트 배열 |

여러 파일을 추출하면 입력 순서대로 결과를 반환합니다.
