# 노드 알아보기

노드는 워크플로우와 챗플로우의 동작을 정의하는 최소 단위입니다. 노드를 조합해 원하는 작업 흐름을 구성합니다.

각 노드는 하나의 역할을 담당합니다. 노드를 연결하면 데이터가 순서대로 흐르는 워크플로우가 만들어집니다.

예를 들어, 시작 → 지식 검색 → LLM → 답변 노드로 질의응답 흐름을 구성할 수 있습니다.

### 기본 노드

워크플로우의 시작과 끝을 담당하는 노드입니다.

| 노드                       | 설명                                   |
| ------------------------ | ------------------------------------ |
| [시작](undefined/start.md) | 워크플로우의 출발점입니다. 사용자 입력을 다음 노드로 전달합니다. |
| [끝/답변](undefined/end.md) | 워크플로우의 마침점입니다. 처리 결과를 사용자에게 전달합니다.   |

| ------------------------------------------- | ---------------------------- |
| [LLM](undefined-1/llm.md)                   | 프롬프트를 전달해 텍스트를 생성합니다.        |
| [의도 분류](undefined-1/question-classifier.md) | 사용자 입력의 의도를 판별합니다.           |
| [변수 추출](undefined-3/parameter-extractor.md) | 텍스트에서 필요한 정보를 추출해 변수로 분리합니다. |
