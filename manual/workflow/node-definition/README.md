# 노드 알아보기

노드는 워크플로우와 챗플로우를 구성하는 최소 단위입니다. 각 노드는 하나의 작업을 수행합니다.

노드를 연결하면 데이터가 순서대로 흐르는 작업 과정을 만들 수 있습니다.

예를 들어, 시작 → 지식 검색 → LLM → 끝/답변으로 질의응답 흐름을 구성합니다.

### 필수 노드

워크플로우의 시작과 종료를 담당합니다.

| 노드                       | 설명                                 |
| ------------------------ | ---------------------------------- |
| [시작](undefined/start.md) | 사용자 입력 또는 외부 데이터를 받아 다음 노드로 전달합니다. |
| [끝/답변](undefined/end.md) | 워크플로우의 처리 결과를 출력합니다.               |

### 기본 노드

AI 모델과 지식을 활용해 작업을 수행합니다.

| 노드                                             | 설명                                  |
| ---------------------------------------------- | ----------------------------------- |
| [LLM](undefined-1/llm.md)                      | AI 모델을 호출해 텍스트를 생성하거나 분석합니다.        |
| [에이전트](undefined-1/undefined.md)               | 지식, 도구, 모델, 메모리를 결합해 복잡한 작업을 수행합니다. |
| [지식 검색](undefined-1/knowledge-retrieval.md)    | 등록된 지식에서 질문과 관련된 내용을 검색합니다.         |
| [지식 추가](undefined-1/knowledge-add.md)          | 실행 중 생성한 텍스트 또는 파일을 지식에 추가합니다.      |
| [인덱싱 상태 확인](undefined-1/knowledge-indexing.md) | 추가한 지식의 인덱싱 진행 상태를 확인합니다.           |
| [의도분류](undefined-1/question-classifier.md)     | 사용자 질문의 의도를 분류하고 결과에 따라 경로를 분기합니다.  |

### 논리 노드

조건에 따라 실행 경로를 제어하거나 작업을 반복합니다.

| 노드                               | 설명                              |
| -------------------------------- | ------------------------------- |
| [조건](undefined-2/if-else.md)     | 변수 값을 규칙과 비교해 실행 경로를 분기합니다.     |
| [반복](undefined-2/iteration.md)   | 배열의 각 항목에 같은 작업을 반복 실행합니다.      |
| [루프](undefined-2/loop.md)        | 조건이 충족될 때까지 작업을 반복 실행합니다.       |
| [인터럽트](undefined-2/interrupt.md) | 실행을 일시 정지하고, 사용자 응답 후 다시 시작합니다. |
