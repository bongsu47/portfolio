# 루프

루프 노드는 특정 조건이 충족될 때까지 작업을 반복합니다.\
원하는 결과가 나올 때까지 순서대로 실행할 수 있습니다.

<figure><img src="../../../../.gitbook/assets/image (652).png" alt=""><figcaption></figcaption></figure>

### 반복 노드와 비교

반복 노드와 루프 노드는 모두 작업을 여러 번 실행합니다.\
반복을 종료하는 기준이 다릅니다.

**반복 노드**는 배열의 각 항목을 처리합니다.\
배열 크기가 실행 횟수를 정합니다.

**루프 노드**는 배열 없이도 실행합니다.\
성공하거나 기준을 충족할 때까지 같은 작업을 반복합니다.

|        | 반복 노드              | 루프 노드                |
| ------ | ------------------ | -------------------- |
| 입력     | 배열 (목록) 필수         | 배열 없이도 사용 가능         |
| 반복 횟수  | 배열 크기만큼 (정해져 있음)   | 조건 충족 시까지 (유동적)      |
| 종료 조건  | 배열의 모든 항목 처리 완료    | 중단 조건 충족 또는 최대 횟수 도달 |
| 병렬 실행  | 지원                 | 미지원                  |
| 적합한 상황 | "이 목록의 각 항목을 처리해줘" | "성공할 때까지 재시도해줘"      |

### 역할

중단 조건을 충족하거나 최대 횟수에 도달할 때까지 작업을 반복합니다.

다음과 같은 작업에 사용할 수 있습니다.

* AI 답변이 품질 기준을 충족할 때까지 다시 생성
* 필요한 데이터를 모두 수집할 때까지 반복 수집
* 지식 인덱싱이 완료될 때까지 상태 확인

### 설정

#### 최대 반복 횟수

<figure><img src="../../../../.gitbook/assets/image (653).png" alt=""><figcaption></figcaption></figure>

루프의 최대 실행 횟수를 설정합니다.\
중단 조건을 충족하지 않아도 최대 횟수에 도달하면 종료합니다.

* 기본값: 10회
* 범위: 1\~100회
* 슬라이더 또는 숫자 입력으로 설정

{% hint style="info" %}
**안전장치**

최대 반복 횟수는 무한 루프를 방지합니다.\
중단 조건에 문제가 있어도 최대 횟수에서 멈춥니다.

루프의 최대 실행 시간은 **5분**입니다.\
횟수와 관계없이 5분을 초과하면 자동으로 중단됩니다.
{% endhint %}

#### 루프 변수

<figure><img src="../../../../.gitbook/assets/image (654).png" alt=""><figcaption></figcaption></figure>

루프 변수는 반복 중에 변하는 값을 저장합니다.\
초기값으로 시작하고, 반복마다 값을 갱신해 상태를 유지합니다.

**+ 추가**를 선택하면 변수를 추가합니다.

<figure><img src="../../../../.gitbook/assets/image (656).png" alt=""><figcaption></figcaption></figure>

루프 뒤에서 내부 결과를 사용하려면 변수 할당 노드로 루프 변수에 저장하세요.

`index` 변수도 자동으로 제공됩니다.\
현재 반복 순서를 나타내며 0부터 시작합니다.

{% hint style="info" %}
**루프 변수 활용**

**성공 여부 추적**

* `success`를 `false`로 시작합니다.
* API 호출에 성공하면 `true`로 갱신합니다.
* `success = true`에서 루프를 종료합니다.

**결과 수집**

* `results`를 빈 배열 `[]`로 시작합니다.
* 반복마다 결과를 배열에 추가합니다.
* 원하는 수만큼 수집하면 종료합니다.

**카운터**

* `count`를 `0`으로 시작합니다.
* 특정 조건에서 1씩 증가시킵니다.
* 목표값에 도달하면 종료합니다.
{% endhint %}

#### 중단 조건

루프를 멈출 조건을 설정합니다.\
각 반복이 끝날 때 검사하고, 충족되면 종료합니다.

**+ 추가**를 선택하면 조건을 추가합니다.

각 조건은 비교 변수, 연산자, 비교 값으로 구성됩니다.\
연산자는 조건 노드와 같습니다.

여러 조건은 **AND** 또는 **OR**로 조합할 수 있습니다.

| 조건 연산자  | 설명              | 예시                                                |
| ------- | --------------- | ------------------------------------------------- |
| **AND** | 모든 조건이 충족되어야 중단 | `success = true` AND `count ≥ 3` → 둘 다 만족해야 루프 종료 |
| **OR**  | 하나라도 충족되면 중단    | `success = true` OR `count ≥ 5` → 하나만 만족해도 루프 종료  |

{% hint style="info" %}
**중단 조건이 없는 경우**

중단 조건이 없으면 최대 반복 횟수까지 실행합니다.\
정확히 N번 반복할 때 사용할 수 있습니다.
{% endhint %}

#### 루프 종료 노드

중단 조건과 같은 역할을 하는 내부 노드입니다.\
실행되면 즉시 루프를 종료합니다. 추가 설정은 필요하지 않습니다.

<figure><img src="../../../../.gitbook/assets/image (657).png" alt=""><figcaption></figcaption></figure>

중단 조건은 각 반복이 끝날 때 자동으로 검사합니다.\
루프 종료 노드는 원하는 위치에 배치할 수 있습니다.\
조건 노드와 연결하면 특정 상황에서만 루프를 종료할 수 있습니다.

중단 조건과 함께 사용할 수 있습니다.\
루프 종료 노드가 먼저 실행되면 즉시 종료합니다.

### 출력 변수

루프가 종료되면 다음 값을 반환합니다.

| 변수           | 설명                                   |
| ------------ | ------------------------------------ |
| 루프 변수들       | 정의한 각 루프 변수의 **최종 값** (마지막 반복 시점의 값) |
| `loop_round` | 실제로 실행된 반복 횟수                        |

예를 들어 최대 반복을 10회로 설정합니다.\
세 번째 반복에서 중단 조건을 충족하면 다음 값을 반환합니다.

* `loop_round` = 3
* 루프 변수: 세 번째 반복까지 갱신한 최종값
