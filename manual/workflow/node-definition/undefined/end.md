# 끝/답변

끝과 답변 노드는 워크플로우의 처리 결과를 내보냅니다. 워크플로우 유형에 따라 노드 이름과 동작이 달라집니다.

<figure><img src="../../../../.gitbook/assets/image (612).png" alt="" width="289"><figcaption></figcaption></figure>

| 워크플로우 유형 | 노드 이름  | 역할                |
| -------- | ------ | ----------------- |
| 워크플로우    | **끝**  | 최종 출력 변수를 정의합니다.  |
| 챗플로우     | **답변** | 사용자에게 메시지를 전달합니다. |

두 노드 모두 워크플로우 결과를 내보냅니다.

### 끝 노드

끝 노드는 워크플로우 실행을 종료하고 최종 출력값을 정의합니다. 이전 노드에서 생성한 값 중 결과로 내보낼 값을 선택합니다.

* LLM 노드에서 생성한 답변을 결과로 내보낼 수 있습니다.
* 코드 노드에서 계산한 값을 결과로 내보낼 수 있습니다.

조건 분기를 사용하면 각 경로에 별도의 끝 노드를 추가할 수 있습니다. 각 경로에서 다른 결과를 정의할 수 있습니다.

<figure><img src="../../../../.gitbook/assets/image (615).png" alt="" width="563"><figcaption></figcaption></figure>

워크플로우는 끝 노드에 도달하면 실행을 완료합니다.

### 답변 노드

답변 노드는 챗플로우의 처리 결과를 사용자에게 메시지로 전달합니다. 이전 노드에서 생성한 값을 조합해 하나의 답변으로 표시합니다.

답변 노드는 흐름 중간에도 여러 개를 배치할 수 있습니다. 진행 상태나 중간 결과를 안내할 때 사용합니다.

<figure><img src="../../../../.gitbook/assets/image (613).png" alt="" width="563"><figcaption></figcaption></figure>

* LLM이 생성한 답변을 사용자에게 표시합니다.
* 지식 검색 결과와 LLM 답변을 함께 전달합니다.
* 파일, 진행 상태 또는 중간 결과를 안내합니다.

답변은 실시간 스트리밍으로 표시됩니다.

### 끝 노드 설정

#### 출력 변수 추가

* 최종 결과로 내보낼 변수를 추가합니다.
* 변수 이름은 워크플로우의 최종 출력 키가 됩니다.

{% hint style="info" %}
#### 출력 변수 사용 시점

출력 변수는 필수가 아닙니다. 메일 발송처럼 실행만 필요한 작업은 별도 출력 없이 구성할 수 있습니다.

외부 API와 연동하거나 에이전트가 워크플로우를 도구로 호출하면, 끝 노드의 출력 변수만 최종 결과로 전달됩니다.
{% endhint %}

#### 변수 선택

이전 노드에서 생성한 변수 중 결과로 내보낼 값을 선택합니다. 필요한 경우 여러 변수를 선택할 수 있습니다.

### 답변 노드 설정

* 직접 메시지를 입력하거나 `/`로 변수를 삽입합니다.
* 이전 노드에서 생성한 변수를 선택해 사용합니다.
* 메시지와 변수를 함께 또는 각각 사용할 수 있습니다.
