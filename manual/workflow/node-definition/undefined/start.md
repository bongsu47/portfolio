# 시작

시작 노드는 워크플로우의 출발점입니다. 사용자 또는 외부 시스템의 입력을 받아 다음 노드로 전달합니다.

<figure><img src="../../../../.gitbook/assets/image (637).png" alt="" width="292"><figcaption></figcaption></figure>

### 역할

시작 노드는 워크플로우에 필요한 입력을 변수로 정의합니다. 정의한 값은 LLM, 조건, 지식 검색 같은 다음 노드에서 사용할 수 있습니다.

* 사용자가 질문을 입력하면 질문이 시작 노드로 전달됩니다.
* 사용자가 파일을 업로드하면 파일 정보가 시작 노드로 전달됩니다.

### 사용 원칙

* 모든 워크플로우에는 시작 노드가 필요합니다.
* 하나의 워크플로우에는 시작 노드를 하나만 사용할 수 있습니다.

### 설정

<figure><img src="../../../../.gitbook/assets/image (638).png" alt="" width="234"><figcaption></figcaption></figure>

#### 변수 유형

**텍스트와 문단**

* 텍스트와 문단은 일반 문자를 입력받습니다.
* **텍스트**는 짧은 입력에 사용하며, 최대 100자까지 입력할 수 있습니다.
* **문단**은 긴 입력에 사용하며, 최대 100,000자까지 입력할 수 있습니다.

두 유형은 최대 입력 길이만 다릅니다.

**목록**

목록은 미리 지정한 항목 중 하나를 선택하는 입력 유형입니다. 사용자 화면에서는 드롭다운으로 표시됩니다.

외부 API에서 값을 전달할 때는 목록 항목과 정확히 일치해야 합니다. 값이 다르면 오류가 발생할 수 있습니다.

**숫자**

숫자 유형은 문자와 특수문자를 허용하지 않습니다. 수량, 금액, 점수 또는 횟수처럼 계산과 비교가 필요한 값에 사용합니다.

**단일 파일과 다중 파일**

단일 파일과 다중 파일은 파일을 입력받는 유형입니다.

* **입력 방식:** 로컬 파일을 업로드하거나 파일 URL을 입력합니다.
* **파일 유형:** 기본적으로 모든 유형을 허용합니다. 필요한 유형 또는 확장자만 허용하도록 제한할 수 있습니다.

두 유형은 업로드할 수 있는 파일 수만 다릅니다.

#### 변수 이름

변수 이름은 시스템에서 사용할 식별자입니다. 영문으로 공백 없이 작성합니다. 입력값의 의미를 알 수 있는 이름을 사용하세요.

#### 입력 필드 이름

입력 필드 이름은 사용자 화면에 표시됩니다. 짧은 이름 또는 질문 형태로 작성할 수 있습니다.

<figure><img src="../../../../.gitbook/assets/image (641).png" alt="" width="278"><figcaption></figcaption></figure>

#### 최대 길이

텍스트와 문단 유형에 입력할 최대 문자 수를 설정합니다.

`input form must be less than 1 characters` 오류는 입력값이 설정한 최대 길이를 초과했음을 의미합니다. 최대 길이를 늘리거나 문단 유형으로 변경합니다.

<figure><img src="../../../../.gitbook/assets/image (630).png" alt="" width="320"><figcaption></figcaption></figure>

#### 필수 옵션

필수 입력은 기본으로 활성화됩니다. 항상 제공되지 않는 값이라면 필수 입력을 비활성화합니다.

필수 입력에 값이 없으면 워크플로우가 실행되지 않습니다. 이때 `필수 입력값을 입력해주세요` 오류가 표시됩니다.

<figure><img src="../../../../.gitbook/assets/image (631).png" alt="" width="173"><figcaption></figcaption></figure>

### 시스템 변수

시스템 변수는 입력 변수를 별도로 정의하지 않아도 기본으로 제공됩니다.

<figure><img src="../../../../.gitbook/assets/image (635).png" alt="" width="195"><figcaption></figcaption></figure>

#### 사용자 입력

사용자 입력 변수는 챗플로우에서만 사용할 수 있습니다.

* 사용자 메시지는 `sys.query`로 전달됩니다.
* 채팅 입력창에서 업로드한 파일은 `sys.files`로 전달됩니다.

<figure><img src="../../../../.gitbook/assets/image (632).png" alt="" width="399"><figcaption></figcaption></figure>

| 변수        | 설명                 | 활용 예시                |
| --------- | ------------------ | -------------------- |
| sys.query | 사용자가 방금 입력한 메시지    | LLM에서 사용자의 질문, 지식 검색 |
| sys.files | 사용자가 함께 업로드한 파일 목록 | 문서 분석, 이미지 처리        |

{% hint style="warning" %}
일반 워크플로우에서는 `sys.query`와 `sys.files`를 사용할 수 없습니다. 시작 노드에서 정의한 입력 변수를 사용하세요.
{% endhint %}

#### 사용자 정보

사용자 정보 변수에는 현재 앱 사용자의 정보가 포함됩니다. 환영 메시지와 이메일 전송 등에 활용합니다.

| 변수              | 설명         | 활용 예시   |
| --------------- | ---------- | ------- |
| sys.user\_name  | 사용자의 이름    | 개인화된 인사 |
| sys.user\_email | 사용자의 이메일   | 메일 전송   |
| sys.user\_id    | 사용자의 고유 ID | 사용자별 처리 |

#### 대화 맥락

대화 맥락 변수에는 현재 대화 정보가 포함됩니다. 채팅 옵션을 활성화한 경우에만 사용할 수 있습니다.

| 변수                   | 설명           | 활용 예시           |
| -------------------- | ------------ | --------------- |
| sys.conversation\_id | 현재 대화의 고유 ID | API 연동 시        |
| sys.dialogue\_count  | 누적 메시지 수     | 메시지 수에 따른 조건 분기 |

#### 시간

시간 변수로 현재 날짜와 시간을 바로 확인합니다. 시간 기준 검색이나 응답에 활용할 수 있습니다.

| 변수           | 설명               | 활용 예시    |
| ------------ | ---------------- | -------- |
| sys.datetime | 현재 날짜 및 시간 (KST) | 시간 기반 응답 |
