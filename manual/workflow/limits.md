# 워크플로우 제한사항

워크플로우를 설계하고 실행할 때 다음 제한사항이 적용됩니다.

제한을 초과하면 워크플로우를 저장하거나 실행할 수 없습니다.

| 항목             | 제한    |
| -------------- | ----- |
| 최대 노드 개수       | 200개  |
| 트리 깊이 제한       | 50    |
| 병렬 최대 분기 수     | 10개   |
| 병렬 최대 중첩 깊이    | 3단계   |
| 루프 노드 최대 반복 횟수 | 100회  |
| 반복 노드 최대 반복 횟수 | 제한 없음 |

### 최대 노드 수

하나의 워크플로우에는 최대 200개의 노드를 배치할 수 있습니다.

시작과 끝 노드를 포함한 모든 노드를 합산합니다.

### 트리 깊이

트리 깊이는 시작 노드부터 끝 노드까지 가장 긴 경로의 노드 수입니다.

최대 깊이는 50입니다.

```
시작 → A → B → C → ... → 끝     ← 경로 1 (깊이 = N)
           └→ D → E → 끝         ← 경로 2 (깊이 = 5)
```

분기가 여러 개면 가장 긴 경로를 기준으로 계산합니다.

흐름이 길어지면 처리 시간과 오류 가능성이 늘어납니다.

### 병렬 처리

#### 최대 분기 수

병렬 노드는 동시에 최대 10개로 분기할 수 있습니다.

```
          ┌→ 분기 1
          ├→ 분기 2
병렬 노드 ├→ 분기 3
          ├→ ...
          └→ 분기 10   ← 최대 10개
```

#### 최대 중첩 깊이

병렬 노드는 최대 3단계까지 중첩할 수 있습니다.

```
병렬 노드 A (1단계)
├── 분기 1: LLM 노드
└── 분기 2: 병렬 노드 B (2단계)              ← 허용
            ├── 분기 2-1: 코드 노드
            └── 분기 2-2: 병렬 노드 C (3단계)        ← 허용
                          ├── ...
                          └── 병렬 노드 D (4단계)     ← 제한 초과!
```

4단계부터는 병렬 노드를 중첩할 수 없습니다.

### 반복

| 노드    | 최대 반복 횟수 | 설명                         |
| ----- | -------- | -------------------------- |
| 루프 노드 | 100회     | 조건이 충족되지 않더라도 100회 후 자동 종료 |
| 반복 노드 | 제한 없음    | 입력 목록의 항목 수만큼 반복           |

#### 루프 노드

루프 노드는 무한 반복을 방지하기 위해 최대 100회 실행됩니다.

#### 반복 노드

반복 노드는 입력 목록의 항목 수만큼 실행됩니다.
