# 워크플로우 이해하기

## 워크플로우와 챗플로우

워크플로우는 여러 노드를 연결해 작업을 자동으로 처리하는 앱입니다. 각 노드는 AI 호출, 지식 검색 또는 조건 분기처럼 하나의 기능을 담당합니다.

워크플로우는 채팅 설정 여부에 따라 두 가지 방식으로 사용할 수 있습니다.

{% include "../../.gitbook/includes/workflow-create-mode.md" %}

다음 기능은 채팅 설정을 켠 챗플로우에서 사용할 수 있습니다.

| 옵션           | 설명                    |
| ------------ | --------------------- |
| **시작 시 채팅창** | 대화형 인터페이스             |
| **환영 메시지**   | 대화 시작 시 보여줄 인사말       |
| **질문 제안**    | AI가 다음에 할 수 있는 질문을 추천 |
| **메모리**      | LLM 노드에서 이전의 입력내용을 기억 |

## 구성 요소

### 노드

노드는 앱 동작을 정의하는 최소 단위입니다. LLM, 지식, 답변 같은 기본 노드와 도구 노드를 사용할 수 있습니다.

### 연결

연결은 노드의 실행 순서를 정의합니다. 연결된 노드는 왼쪽에서 오른쪽으로 실행됩니다.

<figure><img src="../../.gitbook/assets/image (410).png" alt="간단한 워크플로우 구성"><figcaption><p>간단한 워크플로우 예제: 시작 -> LLM -> 종료 순서로 노드가 실행됩니다.</p></figcaption></figure>

### 작업 공간

작업 공간에서 노드를 배치하고 연결해 앱 동작을 구성합니다. 마우스 오른쪽 버튼을 클릭하면 노드 또는 메모를 추가할 수 있습니다.

<figure><img src="../../.gitbook/assets/image (453).png" alt="" width="375"><figcaption><p>&#x3C;노드 추가></p></figcaption></figure>

#### 노드 추가

노드와 도구 목록에서 필요한 항목을 선택합니다. 검색으로 원하는 항목을 빠르게 찾을 수 있습니다. 각 노드의 역할은 [노드 알아보기](node-definition/)에서 확인합니다.

#### 메모 추가

작업 공간에 메모를 남길 수 있습니다.

### 퀵 메뉴

<figure><img src="../../.gitbook/assets/image (250).png" alt=""><figcaption><p>&#x3C;퀵 메뉴></p></figcaption></figure>

* **확대/축소:** 편집 화면을 25%에서 200%까지 확대하거나 축소합니다.
* **노드 추가 및 메모 추가:** 작업 공간에 노드 또는 메모를 추가합니다.
* **포인터 모드:** 노드, 메모 및 연결선을 선택합니다.
* **핸드 모드:** 화면을 드래그해 이동합니다.
* **노드 정리:** 노드를 보기 좋게 자동 배치합니다.
* **실행 취소 및 다시 실행:** 이전 작업을 되돌리거나 다시 적용합니다.

### 앱 조건 설정

<figure><img src="../../.gitbook/assets/image (28).png" alt="" width="440"><figcaption></figcaption></figure>

#### 대화 변수

대화 변수는 챗플로우 전용 기능입니다. 대화가 진행되는 동안 값을 유지합니다.

일반 워크플로우는 실행이 끝나면 변수가 사라집니다. 챗플로우는 이전 대화에서 저장한 값을 다음 대화에도 사용할 수 있습니다.

#### 환경 변수

환경 변수는 개인 정보와 자격 증명을 저장할 때 사용합니다. `Secret` 유형은 앱 내보내기 파일에 포함되지 않습니다.

**+ 추가**를 선택하면 환경 변수를 추가할 수 있습니다.

<figure><img src="../../.gitbook/assets/image (117).png" alt=""><figcaption><p>&#x3C;환경 변수 추가></p></figcaption></figure>

환경 변수는 `String`, `Number`, `Secret` 유형을 지원합니다.

* `String`은 텍스트와 숫자를 입력할 수 있습니다.
* `Number`는 숫자만 입력할 수 있습니다.
* `Secret`은 값을 마스킹하며, 앱 내보내기 파일에 포함하지 않습니다.

### 앱 기능 설정

환영 메시지, 질문 제안, 인용 및 출처, 가드레일, 음성, 파일 입력을 설정합니다.
