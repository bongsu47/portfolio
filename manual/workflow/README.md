# 워크플로우

워크플로우는 노드를 연결해 정해진 순서대로 작업을 처리하는 앱입니다. 반복적이고 정형화된 업무를 안정적으로 자동화할 때 적합합니다.

<figure><img src="../../.gitbook/assets/image (46).png" alt=""><figcaption></figcaption></figure>

### 워크플로우 유형

* **일반 워크플로우:** 정해진 입력을 받아 설계한 흐름대로 작업을 실행합니다.
* **대화형 워크플로우:** 채팅에서 사용자와 대화하며 설계한 흐름을 실행합니다.

### 구성 방식

* **노드:** AI 호출, 지식 검색, 조건 분기처럼 하나의 작업을 수행합니다.
* **연결:** 노드의 실행 순서를 정의합니다. 연결된 노드는 왼쪽에서 오른쪽으로 실행됩니다.
