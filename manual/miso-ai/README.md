# 미소AI

미소AI는 MISO에서 제공하는 **엔터프라이즈 AI 어시스턴트**입니다.

채팅에서 질문하고, 파일과 사내 지식을 연결해 업무를 처리합니다.

사내에서 만든 자동화 앱도 검색하고 즐겨찾기에 추가해 사용할 수 있습니다.
