# 미소 추천 앱

미소AI는 별도 설정 없이 바로 사용할 수 있는 추천 앱을 제공합니다.

목적에 맞는 앱을 선택해 대화로 업무를 처리할 수 있습니다.

### 추천 앱 찾기

{% stepper %}
{% step %}
#### 슬래시 명령어 사용하기

채팅 입력창에 `/`를 입력하면 추천 앱 목록이 표시됩니다.
{% endstep %}

{% step %}
#### 추천 앱 버튼 사용하기

채팅 입력창의 **추천 앱** 버튼을 선택합니다.
{% endstep %}

{% step %}
#### 앱 둘러보기 열기

사이드바의 **앱 둘러보기**에서 추천 앱과 동료가 만든 앱을 확인합니다.
{% endstep %}
{% endstepper %}

### 대표앱Ally: 문제 정의 코치

Ally는 업무 고민이나 아이디어를 대화로 정리해 기획서(PRD)로 만듭니다.

기획 경험이 없어도 Ally의 질문에 답하며 문제를 구체화할 수 있습니다.

#### 이런 경우에 사용합니다

* 반복되는 업무의 개선 방법을 찾을 때
* 아이디어를 어디서부터 정리할지 고민될 때
* 만들고 싶은 도구를 기획서로 정리할 때

<figure><img src="../../.gitbook/assets/스크린샷 2026-07-28 173353.png" alt=""><figcaption></figcaption></figure>

#### 사용 흐름

{% stepper %}
{% step %}
#### 생각 입력하기

정돈되지 않은 생각도 그대로 입력합니다.

떠오르는 불편함이나 하고 싶은 일을 일상 언어로 작성합니다.
{% endstep %}

{% step %}
#### 질문에 답하기

Ally는 문제를 구체화하기 위해 질문합니다.

**선택지 카드**를 선택하거나 원하는 내용을 직접 입력합니다.

같은 맥락은 다시 묻지 않으며, 대화가 쌓일수록 내용이 구체화됩니다.
{% endstep %}

{% step %}
#### 문제 정의 확인하기

내용이 정리되면 Ally가 **문제 정의 카드**를 표시합니다.

* **수정할게요** — 더 다듬고 싶을 때
* **다음 단계로 진행** — 기획서 작성으로 넘어갈 때
{% endstep %}

{% step %}
#### 기획서 완성하기

**다음 단계로 진행**을 선택하면 Ally가 기획서(PRD)를 작성합니다.

기획서에는 개요, 사용자, 만들 기능, 성공의 모습이 포함됩니다. 카드 오른쪽 위에서 복사하거나 다운로드할 수 있습니다.
{% endstep %}

{% step %}
#### 서비스 만들기로 이어가기

완성된 기획서 아래의 **서비스 만들기**를 선택합니다.

기획서 내용을 입력으로 사용해 웹사이트를 만드는 단계로 이동합니다.
{% endstep %}
{% endstepper %}

#### 알아두기

* Ally는 모르는 내용을 임의로 만들지 않습니다. 필요한 정보는 질문으로 확인합니다.
* 응답이 끝나기 전에 화면을 이동하면 답변이 **미완성**으로 남을 수 있습니다. 메시지를 이어서 보내면 계속 진행할 수 있습니다.
* 대화는 **내 채팅** 목록에 저장됩니다.
