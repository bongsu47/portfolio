# 앱 둘러보기

## 앱 둘러보기

미소가 추천하는 앱과 동료가 만든 앱을 한곳에서 둘러보고, **바로 실행**하거나 **즐겨찾기**로 모아 두는 메뉴입니다. 미소 AI 사이드바에서 들어갈 수 있습니다.

<figure><img src="../../.gitbook/assets/스크린샷 2026-06-19 오후 6.06.06.png" alt=""><figcaption></figcaption></figure>



### 화면 구성

**미소 추천 앱**\
미소가 큐레이션한 앱과 워크스페이스의 공개 앱을 카드로 보여줍니다. **더보기**로 전체를 펼쳐 볼 수 있습니다.

**앱 검색**\
앱 **이름·설명·태그**로 검색합니다. 검색창 아래 유형 탭으로 원하는 종류만 추려 볼 수 있습니다.

* **전체 / 에이전트 / 챗플로우 / 워크플로우 / 웹사이트**

### 앱 카드 보는 법

각 카드에는 **아이콘, 앱 이름, 유형, 설명, 태그(#), 제작자**가 표시됩니다.\
카드 우측 상단의 **별(★)** 을 누르면 즐겨찾기에 추가/해제됩니다.

### 앱 실행하기 (유형별)

카드를 클릭하면 앱 유형에 따라 다르게 열립니다.

| 유형              | 클릭하면                     |
| --------------- | ------------------------ |
| **에이전트 · 챗플로우** | 미소 AI 채팅 화면으로 전환되어 바로 대화 |
| **워크플로우**       | **새 창**으로 실행 화면 열림       |
| **웹사이트**        | **새 창**으로 발행된 사이트 열림     |

### 즐겨찾기

별(★)로 지정한 앱은 **좌측 사이드바 즐겨찾기 리스트**에 항상 고정됩니다.\
자주 쓰는 앱을 모아 두고, 리스트에서 클릭해 바로 실행할 수 있습니다.

### 알아두면 좋아요

* ‘내 채팅’ 목록은 **‘미소 AI’ 대화**와 **‘에이전트 앱’ 대화**가 구분되어 표시됩니다.
* 지금 사용할 수 있는 앱만 검색 결과에 노출됩니다.
