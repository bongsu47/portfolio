# 지식 관리

## 지식 등록 방식 선택하기

지식을 만들 때는 **AI 탐색으로 만들기** 또는 **직접 설정해 만들기**를 선택합니다. 같은 자료도 선택한 방식에 따라 읽고 검색하는 방법이 달라집니다.

폴더 구조, 파일 유형, 예상 질문을 기준으로 방식을 선택합니다.

### 빠르게 선택하기

| 자료 또는 목적                   | 권장 방식                 |
| -------------------------- | --------------------- |
| 공유 폴더 전체를 등록하고 최신 상태로 유지   | 🔍 AI 탐색으로 만들기        |
| 엑셀·CSV에서 합계, 평균, 조건별 수치 조회 | 🔍 AI 탐색으로 만들기        |
| 긴 규정집에서 특정 조항 검색           | ⚙️ 직접 설정해 만들기         |
| FAQ처럼 빠르고 일관된 답변이 필요한 서비스  | ⚙️ 직접 설정해 만들기         |
| 한글 문서(`hwp`, `hwpx`)       | ⚙️ 직접 설정해 만들기         |
| 수만 행 이상의 표 파일              | 직접 설정해 만들기 또는 분할 후 등록 |

### 두 방식 비교

| 구분             | 🔍 AI 탐색으로 만들기    | ⚙️ 직접 설정해 만들기  |
| -------------- | ----------------- | -------------- |
| 자료 처리          | 원본 유지 및 파일별 요약 생성 | 청크 분할 및 색인     |
| 검색 방식          | AI가 관련 파일을 선택해 읽음 | 질문과 유사한 청크 검색  |
| 응답 속도          | 상대적으로 느림          | 빠름             |
| 표·수치 조회        | **강함**            | 제한적            |
| 긴 문서의 특정 내용 검색 | 제한적               | **강함**         |
| 많은 문서 검색       | 제한적               | **강함**         |
| 폴더 구조 유지       | 가능                | 불가             |
| 원본 변경 동기화      | 가능                | 불가. 다시 업로드해야 함 |

### 파일 유형별 선택

| 파일 유형                       | 권장 방식                  | 참고                         |
| --------------------------- | ---------------------- | -------------------------- |
| 일반 규모의 `xlsx`, `xls`, `csv` | 🔍 AI 탐색               | 합계·평균·조건별 조회에 적합합니다.       |
| 대용량 `xlsx`, `xls`, `csv`    | ⚙️ 직접 설정 또는 분할 후 AI 탐색 | 표 인식에 실패할 수 있습니다.          |
| `hwp`, `hwpx`               | ⚙️ 직접 설정               | AI 탐색은 한글 문서를 읽지 못합니다.     |
| `pdf`, `docx`, `pptx`       | 목적에 따라 선택              | 두 방식 모두 지원합니다.             |
| `txt`, `md`                 | 어느 방식이든 가능             | 두 방식 모두 처리합니다.             |
| `doc`, `ppt`                | 변환 후 등록                | `docx`, `pptx` 형식으로 변환합니다. |
| 글자를 인식하지 못하는 스캔 PDF         | ⚙️ 직접 설정 + OCR         | 업로드할 때 OCR을 선택합니다.         |
| `jpg`, `png` 등 이미지          | 지원하지 않음                | 이미지 파일 단독 등록은 지원하지 않습니다.   |

### 문서 성격으로 선택하기

`pdf`, `docx`, `pptx`는 질문 방식에 따라 선택합니다.

#### AI 탐색이 적합한 경우

* 폴더 구조가 의미 있는 자료입니다. 예: 부서·연도·주제별 자료.
* 여러 파일을 함께 확인해야 답할 수 있습니다.
* 원본 자료가 자주 추가되거나 변경됩니다.

#### 직접 설정이 적합한 경우

* 긴 문서에서 특정 조항이나 문단을 찾아야 합니다.
* 유사한 문서가 수백 개 이상 있습니다.
* 챗봇처럼 빠르고 일정한 응답이 필요합니다.

{% hint style="warning" %}
**AI 탐색은 파일 앞부분을 기준으로 내용을 판단합니다.**

파일명과 문서 첫 부분에 주제를 명확히 적습니다. 문서 중간에만 있는 세부 내용은 검색에서 누락될 수 있습니다.
{% endhint %}

### 엑셀·CSV 등록 전 확인

일반적인 표 파일은 AI 탐색에 적합합니다. 다만 파일이 크면 표를 데이터베이스 형태로 변환하지 못할 수 있습니다.

변환에 실패한 파일도 등록은 완료될 수 있습니다. 이 경우 파일은 일반 텍스트로 저장됩니다. 합계나 조건별 조회 결과가 정확하지 않을 수 있습니다.

#### 표 크기별 권장 방식

| 표 크기                                         | 권장 방식                  | 참고                                |
| -------------------------------------------- | ---------------------- | --------------------------------- |
| <p>10만 칸 미만<br>예: 20열 × 5,000행</p>           | 🔍 AI 탐색               | 그대로 등록합니다.                        |
| <p>10만 칸 이상, 수만 행 수준<br>예: 20열 × 30,000행</p> | ⚙️ 직접 설정 또는 분할 후 AI 탐색 | 표 인식에 실패할 수 있습니다.                 |
| 10만 행 이상                                     | 정리 후 등록                | 그대로 등록하면 처리 시간이 길어지거나 실패할 수 있습니다. |

{% hint style="warning" %}
**행 수보다 총 칸 수를 확인합니다.**

파일 크기는 `행 × 열`로 판단합니다. 열이 많은 파일은 행 수가 적어도 처리 부담이 큽니다.
{% endhint %}

#### 대용량 표 파일 정리

1. 사용하지 않는 열을 삭제합니다. 칸 수와 검색 범위를 함께 줄일 수 있습니다.
2. 기간 또는 업무 단위로 파일을 나눕니다. 예: 연도별, 분기별, 사업장별.
3. 필요한 집계표를 만들어 등록합니다. 원본 데이터보다 검색 품질이 좋아질 수 있습니다.

{% hint style="info" %}
**AI 탐색은 표의 앞부분을 읽어 파일 성격을 판단합니다.**

첫 시트의 첫 행에 머리글을 배치합니다. 안내문, 빈 행, 로고가 앞에 있으면 파일을 올바르게 판단하지 못할 수 있습니다.
{% endhint %}

### 등록 전 확인사항

#### AI 탐색으로 만들기

* 폴더 구조를 유지한 사본을 저장합니다.
* 파일 수나 용량이 큰 폴더는 처리 시간이 길거나 실패할 수 있습니다.
* 필요한 하위 폴더만 선택합니다.
* 공유하면 안 되는 파일이 폴더에 없는지 확인합니다.
* 읽지 못한 파일이 있어도 등록은 완료될 수 있습니다.
* 등록 후 문서 목록에서 파일 처리 상태를 확인합니다.
* 파일 탐색 과정이 있어 직접 설정 방식보다 응답이 느릴 수 있습니다.

#### 직접 설정해 만들기

* 파일 하나당 최대 **50MB**까지 업로드할 수 있습니다.
* 한 번에 최대 **10개**까지 업로드할 수 있습니다.
* 스캔 PDF는 OCR을 선택해야 내용을 추출할 수 있습니다.

{% hint style="info" %}
**자동**과 **사용자 설정**은 청크 설정입니다.

직접 설정해 만들기에서 선택하는 **자동**과 **사용자 설정**은 문서 분할 방식을 정합니다. 등록 방식이나 OCR 설정과는 관계없습니다.

* **자동**: 문단 기준으로 자동 분할합니다.
* **사용자 설정**: 구분 기호, 청크 크기, 겹침 범위를 직접 설정합니다.
{% endhint %}

### 자주 묻는 질문

#### Q1. 두 방식을 함께 사용할 수 있나요?

가능합니다. 여러 지식을 만들고 하나의 앱에 함께 연결할 수 있습니다. 엑셀은 AI 탐색으로, 규정 문서는 직접 설정으로 등록하는 구성이 적합합니다.

#### Q2. 등록 방식을 나중에 바꿀 수 있나요?

등록 방식은 지식을 만들 때 결정합니다. 방식을 바꾸려면 새 지식을 만들어 다시 등록합니다.

#### Q3. 원본 폴더에서 파일을 삭제하면 지식에서도 삭제되나요?

삭제도 동기화됩니다. 원본을 유지하면서 지식에서만 제외하려면 문서 목록에서 해당 파일을 관리합니다.

#### Q4. AI 탐색으로 등록한 엑셀의 합계가 부정확합니다.

표 인식이 실패했을 수 있습니다. 불필요한 열을 삭제하거나 파일을 나눈 뒤 다시 등록합니다.

#### Q5. 등록했지만 자료 내용이 답변에 나오지 않습니다.

문서 목록에서 파일 처리 상태를 확인합니다. 스캔 PDF, 구버전 문서, 한글 문서가 원인일 수 있습니다.
