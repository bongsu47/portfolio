# AI 탐색으로 만들기

AI 탐색은 폴더 구조와 원본 파일을 유지하는 지식 등록 방식입니다. 질문이 들어오면 AI가 관련 파일을 찾아 직접 읽습니다. 파일별 요약 정보를 먼저 생성한 뒤, 이 정보를 바탕으로 필요한 파일을 선택합니다.

### 소스 선택

지식 관리에서 **지식 추가**를 선택한 뒤, 자료 위치에 맞는 소스를 선택합니다.
{% endstep %}

### 폴더 연결

등록할 폴더를 선택합니다. Google Drive와 SharePoint는 처음 사용할 때 계정을 연결합니다.

* [내 컴퓨터 폴더](local.md)
* [Google Drive · SharePoint](google-drive-sharepoint.md)
{% endstep %}

{% step %}
### 지식 정보 입력

지식 이름과 설명을 입력합니다. 설명에는 폴더의 목적과 포함된 자료를 명확히 작성합니다.
{% endstep %}

{% step %}
### 분석 완료 확인

AI가 폴더의 파일을 분석하고 용어를 추출합니다. 분석이 완료되면 지식을 앱에 연결해 사용할 수 있습니다.
{% endstep %}
{% endstepper %}

### 동기화와 관리

선택한 폴더는 구조를 유지한 사본으로 저장됩니다. 원본 폴더의 파일 추가·수정·삭제는 동기화로 반영됩니다.

등록 후에는 문서 목록에서 파일 처리 상태를 확인합니다. 동기화한 파일은 다시 분석될 수 있습니다.

### 등록 전 확인

* 공유하면 안 되는 파일이 선택한 폴더에 없는지 확인합니다.
* 필요한 하위 폴더만 선택합니다. 파일 수와 용량이 크면 분석 시간이 길어질 수 있습니다.
* 대용량 엑셀·CSV는 열을 줄이거나 파일을 나눈 뒤 등록합니다.

지원 파일 형식과 대용량 표 파일의 기준은 [지식 관리](../)에서 확인합니다.
