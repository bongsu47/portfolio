# 지식 연결하기

에이전트가 답변에 사용할 지식을 연결합니다. **추가**를 선택하면 지식 선택 창이 열립니다.

<figure><img src="../../.gitbook/assets/image (435).png" alt="" width="563"><figcaption><p>지식 선택</p></figcaption></figure>

### 지식 찾기

* **지식 검색:** 사용자가 사용할 수 있는 지식을 검색합니다.
* **내 지식:** 사용자가 임베딩해 사용할 수 있는 지식 목록입니다.
* **공유받은 지식:** 다른 사용자가 임베딩한 지식 목록입니다.
