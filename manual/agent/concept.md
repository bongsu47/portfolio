# 에이전트 이해하기

에이전트는 프롬프트와 도구를 바탕으로 동작하는 챗봇형 앱입니다. \
사용자의 요청을 해석하고 필요한 작업을 수행합니다.

**앱 만들기**에서 에이전트를 생성한 뒤 앱 편집 화면에서 구성합니다.

<figure><img src="../../.gitbook/assets/스크린샷 2026-07-24 141128.png" alt=""><figcaption></figcaption></figure>

### 에이전트 구성하기

#### 프롬프트

프롬프트는 에이전트의 동작과 역할을 정의합니다. 프롬프팅 기법을 사용해 원하는 동작을 구체화합니다.

#### 입력 변수

입력 변수는 에이전트 실행 시 사용자에게 받을 정보를 정의합니다.

텍스트, 문단, 숫자, 목록 유형을 지원합니다.

#### 지식과 도구

**지식 검색**에서 에이전트 답변에 참조할 지식을 연결합니다.

**도구 설정**에서 외부 시스템과 연동하는 도구를 추가합니다.

#### 설정

**설정**에서 에이전트의 세부 동작을 결정합니다.

### 테스트와 운영

* **테스트:** 만든 에이전트를 바로 실행해 확인합니다.
* **미리보기:** 배포 후 사용자에게 표시될 형태를 미리 확인합니다.
* **사용 현황:** 에이전트의 모니터링 정보와 로그를 확인합니다.

### 공유하기

**공유**에서 에이전트의 공유 범위를 설정합니다.

현재 조직 사용자, 모든 조직 사용자, URL 공유를 지원합니다. 자세한 내용은 [공유 · 발행 · 운영](../share-publish-management/)을 확인합니다.
