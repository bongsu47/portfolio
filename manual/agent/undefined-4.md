# 프롬프트 작성하기

프롬프트는 단순한 질문 문구가 아닙니다. 에이전트의 행동과 응답 방식을 설계하는 지침입니다. \
프롬프트에 변수를 포함하는 방식에 따라 에이전트의 답변이 달라질 수 있습니다.

<figure><img src="../../.gitbook/assets/image (822).png" alt=""><figcaption><p>에이전트 프롬프트 변수 설정</p></figcaption></figure>

{% hint style="info" %}
#### 프롬프트를 더 자세히 작성하려면

[프롬프트 작성 가이드](../../study/prompt/)에서 작성 기법과 예시를 확인합니다.
{% endhint %}

{% hint style="info" %}
#### 최신 모델을 자동으로 적용할 수 있나요?

가능합니다. 모델 선택 목록에서 **Latest** 모델을 선택합니다.

모델 공급자와 모델 패밀리별로 **Latest**가 표시된 모델을 선택할 수 있습니다.

선택한 모델은 MISO에서 공식 지원하며 워크스페이스에서 사용할 수 있는 최신 모델로 자동 적용됩니다.

모델 버전이 업데이트되어도 추가 설정 없이 최신 모델을 앱에 반영합니다.
