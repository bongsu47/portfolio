# 파일 입력 설정하기

사용자가 질문과 함께 업로드할 파일의 입력 방식과 제한을 설정합니다.

<figure><img src="../../../.gitbook/assets/image (442).png" alt=""><figcaption><p>파일 설정</p></figcaption></figure>

파일 입력을 사용하면 사용자가 질문에 파일을 첨부할 수 있습니다.

<figure><img src="../../../.gitbook/assets/image (443).png" alt=""><figcaption><p>파일 업로드 설정</p></figcaption></figure>

### 설정 항목

* **입력 방식:** 로컬 파일 업로드, URL 입력 또는 두 방식을 모두 허용할지 선택합니다.
* **개수 제한:** 한 번에 업로드할 수 있는 최대 파일 수를 설정합니다.
* **파일 유형:** 문서 파일 또는 이미지 파일을 허용합니다.
