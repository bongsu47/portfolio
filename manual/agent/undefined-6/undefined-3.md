# 보안(가드레일) 설정하기

가드레일과 키워드 필터로 앱의 입력 및 출력을 검증합니다.

<figure><img src="../../../.gitbook/assets/image (444).png" alt=""><figcaption><p>보안 설정</p></figcaption></figure>

### 가드레일

가드레일은 입력과 출력의 안전성, 적절성 및 규정 준수를 검증합니다. 기본 설정은 관리자가 관리합니다. 관리자가 설정 강제를 해제하면 사용자가 직접 변경할 수 있습니다.

### 설정 항목

* **차단 모드:** 가드레일이 감지한 메시지를 차단할지 설정합니다.
* **키워드 필터:** 지정한 키워드를 감지해 메시지를 필터링합니다.
* **차단 시 대체 메시지:** 차단된 메시지 대신 표시할 안내 문구를 설정합니다.
