# 입력 변수 설정하기

입력 변수는 앱 실행 시 사용자에게 받을 정보를 정의합니다. \
에이전트는 텍스트, 문단, 목록, 숫자 유형을 지원합니다.

### 텍스트와 문단

* **텍스트:** 최대 `100`자까지 입력합니다.
* **문단:** 최대 `10,000,000`자까지 긴 내용을 입력합니다.

### 목록

* **단일 선택:** 목록에서 하나의 옵션을 선택합니다.
* **다중 선택:** 목록에서 여러 옵션을 선택합니다.

숫자 입력은 숫자만 받을 때 사용합니다.
