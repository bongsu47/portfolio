# 웹사이트

## **웹사이트 앱 만들기(코딩 에이전트)**

### **1. 시작하기**

1. 상단 메뉴에서 **앱 만들기** 화면에 진입합니다.
2. "어떤 유형의 AI앱을 만들고 싶으신가요?" 화면에서 **웹사이트** 카드를 선택합니다.
   * 웹사이트: "AI에게 설명하면 웹사이트가 만들어지고, 바로 배포할 수 있어요."
3. **기본 정보 입력** 화면에서 앱 이름을 입력하고 **다음** 버튼을 클릭합니다.

<table><thead><tr><th width="102.26953125">입력 항목</th><th width="101.59765625">필수 여부</th><th width="320.40625">설명</th></tr></thead><tbody><tr><td><strong>이름</strong></td><td>필수</td><td>앱 이름을 입력합니다. (최대 50자)</td></tr><tr><td><strong>소개</strong></td><td>선택</td><td>앱의 목적을 간단히 소개합니다. (최대 180자)</td></tr></tbody></table>

> ℹ️ 참고
>
> "다음" 버튼을 클릭하면 바로 웹사이트 에디터 화면으로 이동합니다. \
> &#xNAN;_(단, 에디터 최초 진입시 환경 세팅을 위해 약 1\~2분 대기 시간이 소요됩니다. 조금만 기다려주세요^^)_

#### 첫 진입 온보딩

처음 들어가면 환경 세팅 동안 **온보딩 캐러셀**이 자동으로 재생되며, 채팅·셀렉터·발행 등의 핵심 기능을 짧게 안내합니다. 닫지 않아도 준비가 끝나면 자동으로 사라지고 작업을 시작할 준비가 완료됩니다.

#### 에디터(웹사이트 작업) 접근 권한

생성자 혹은 편집 권한이 있는 사용자만 에디터에 진입하여 작업을 진행할 수 있습니다. 생성된 앱에 대한 **편집자 권한이 없는 경우**, 에디터 대신 생성된 웹사이트(읽기 전용)로 안내됩니다.

### **3. AI와 대화하여 웹사이트 만들기**

좌측 **채팅 패널**에서 AI와 대화하며 웹사이트를 제작합니다.

1. 하단 **메시지 입력창**에 만들고 싶은 웹사이트에 대한 설명을 입력합니다.
2. AI가 요청을 분석하고 코드를 생성하며, 우측 **Preview** 탭에서 결과를 실시간으로 확인할 수 있습니다.
3. 수정이 필요한 부분이 있으면 채팅으로 추가 요청을 보냅니다.

메시지 입력 시 **`@`** 를 입력하면 프로젝트 내 사전 설정된 앱이나 도구를 참조할 수 있습니다. (지정할 도구 or APP 선택 후 ‘Enter’ 키 입력으로 반영) 특정 요소를 지정하여 AI에게 수정 요청을 할 때 유용합니다.

#### **요소 선택(셀렉터) 기능**

메시지 입력창 하단의 **선택(셀렉터) 버튼**을 클릭하면 **요소 선택 모드**에 진입합니다. Preview 화면에서 수정하고 싶은 디자인 요소를 직접 클릭하여 AI에게 정확한 수정 요청을 보낼 수 있습니다.



**사용 방법**

1. 메시지 입력창 하단의 **선택(셀렉터) 버튼**을 클릭합니다. 버튼이 활성화(강조) 상태로 변합니다.
2. Preview 화면에서 커서가 **십자(+) 모양**으로 변경됩니다.
3. 수정하고 싶은 요소에 마우스를 올리면 **녹색 오버레이**와 함께 요소 정보 툴팁이 표시됩니다.
4. 요소를 **클릭**하면 선택이 완료되고, 메시지 입력창 위에 **선택 칩**이 나타납니다.
5. 메시지 입력창에 수정 요청을 입력합니다. (예: "이 버튼의 색을 파란색으로 변경해줘")
6. 메시지를 전송하면 AI가 선택된 요소의 위치와 스타일 정보를 바탕으로 정확하게 수정합니다.

**선택 칩 관리**

<div align="left"><figure><img src="../.gitbook/assets/image (760).png" alt="" width="375"><figcaption></figcaption></figure></div>

* 선택된 요소는 입력창 위에 **칩(badge)** 형태로 표시됩니다.
* 칩에 마우스를 올리면 해당 요소의 **컴포넌트 경로, DOM 구조, 소스 파일 위치** 등 상세 정보를 확인할 수 있습니다.
* 각 칩의 **✕ 버튼**을 클릭하여 개별 선택을 해제하거나, **전체 해제** 버튼으로 모든 선택을 초기화할 수 있습니다.
* 여러 요소를 순차적으로 클릭하여 **다중 선택**도 가능합니다.

> _**✅ 팁**_&#x20;
>
> _수정하고 싶은 요소를 직접 선택한 뒤 요청하면, AI가 해당 요소의 소스 파일과 스타일을 정확히 파악하여 수정하므로 **텍스트로만 설명하는 것보다 훨씬 빠르고 정확한 결과**를 얻을 수 있습니다._

#### **파일 첨부**

메시지 입력창의 \*\*`+` 버튼 → "파일 첨부"\*\*를 클릭하여 참고 이미지나 문서를 첨부할 수 있습니다. \
디자인 시안이나 레퍼런스 이미지를 전달할 때 활용합니다.

> _**✅ 팁**_&#x20;
>
> _• 처음 요청을 **구체적으로 작성할수록** AI가 더 정확한 결과물을 생성합니다._&#x20;
>
> _• 예시: "헤더, 메인 섹션, 푸터가 있는 회사 소개 페이지를 만들어줘. 메인 컬러는 파란색이고, 반응형으로 제작해줘."_

#### **메시지 전송·중단 관리**

* **대기 메시지 취소**: 생성 대기 중인 메시지는 메시지 앞의 **✕ 버튼**으로 취소할 수 있습니다.
* **생성 중단**: AI가 작업 중일 때 **`ESC` 키를 두 번** 누르면 생성을 중단합니다. (실수 방지를 위한 더블 탭)

### **6. 요구사항 정의하기**

메시지 입력창의 \*\*`+` 버튼 → "요구사항"\*\*을 클릭하면 프로젝트 설정 모달이 열립니다. 웹사이트의 스펙과 디자인 가이드라인을 문서로 관리할 수 있습니다.

#### **탭 구성**

<table><thead><tr><th width="127.23046875">탭</th><th width="355.953125">설명</th></tr></thead><tbody><tr><td><strong>제품 요구사항</strong></td><td>제품의 기능과 요구사항을 정의합니다.</td></tr><tr><td><strong>디자인</strong></td><td>시각 디자인 및 인터랙션 가이드라인을 설명합니다.</td></tr></tbody></table>

#### **사용 방법**

1. **`+` 추가** 버튼을 클릭하여 새 요구사항 문서를 생성합니다.
2. 파일명과 내용을 작성한 뒤 **저장(✓)** 버튼을 클릭합니다.
3. 작성된 요구사항은 AI가 웹사이트를 생성할 때 참고 자료로 활용합니다.

> _**✅ 팁**_&#x20;
>
> _요구사항을 미리 정의해 두면 AI가 대화 맥락을 더 잘 이해하고, **일관된 품질의 결과물**을 생성합니다. 복잡한 프로젝트일수록 요구사항 문서를 활용하는 것을 권장합니다._

### **7. 연동 관리하기**

채팅 입력창의 **`+` 버튼**을 클릭한 뒤 \*\*"연동 관리"\*\*를 선택하면 프로젝트 설정 모달이 열립니다. 웹사이트에서 활용할 MISO 앱, 도구, 모델, MCP, 지식(데이터셋) 등을 연결할 수 있습니다.

#### **프로젝트 설정 모달 탭**

<table><thead><tr><th width="111.8515625">탭</th><th width="369.01171875">설명</th></tr></thead><tbody><tr><td><strong>연동 관리</strong></td><td>앱, 도구, 모델, 지식, MCP 등을 연결/해제합니다.</td></tr><tr><td><strong>요구사항</strong></td><td>제품 요구사항 및 디자인 가이드라인을 정의합니다.</td></tr><tr><td><strong>환경변수</strong></td><td>API 키 등 환경변수를 설정합니다.</td></tr></tbody></table>

#### **연동 항목 필터**

상단의 필터 탭을 사용하여 카테고리별로 연동 항목을 확인할 수 있습니다.

<table><thead><tr><th width="81.40625">필터</th><th>설명</th></tr></thead><tbody><tr><td><strong>전체</strong></td><td>모든 연동 항목을 표시합니다.</td></tr><tr><td><strong>앱</strong></td><td>챗플로우, 워크플로우, 에이전트 등 다른 MISO 앱을 연동합니다.</td></tr><tr><td><strong>도구</strong></td><td>API 도구, 빌트인 도구 등 외부 도구를 연동합니다.</td></tr><tr><td><strong>모델</strong></td><td>OpenAI, Claude 등 LLM 모델을 연동합니다.</td></tr><tr><td><strong>MCP</strong></td><td>MCP(Model Context Protocol) 연동을 설정합니다.</td></tr><tr><td><strong>지식</strong></td><td>데이터셋(지식)을 연동합니다. 연동 시 전용 API 토큰이 자동 발급되어, 웹사이트에서 지식 검색 결과를 활용할 수 있습니다.(단, API 접근 활성 권한을 가지는 지식 편집자 이상의 권한이 필요합니다.)</td></tr></tbody></table>

#### **연동 추가/제거 방법**

1. **검색창**에서 원하는 연동 항목을 검색합니다.
2. 필터 탭을 선택하여 카테고리별로 탐색할 수 있습니다.
3. 항목을 **클릭하면 연동이 추가**되며, 체크(✓) 아이콘이 표시됩니다.
4. 이미 연동된 항목을 다시 클릭하면 **연동이 해제**됩니다.
5. 상단의 선택된 항목 영역에서 **✕ 버튼**을 클릭하여 빠르게 제거할 수도 있습니다.

> _**ℹ️ 참고**_&#x20;
>
> _연동된 항목은 채팅 입력창 위에 스트립 형태로 표시됩니다. 연동된 앱/도구를 대화에서 활용하려면 AI에게 해당 도구의 사용을 요청하세요._

> _**✅ 팁**_&#x20;
>
> _연동 항목은 제공업체별로 그룹화되어 표시됩니다. 예를 들어 Google 항목은 Google Drive, Google Sheets 등이 하나의 섹션으로 묶여 나타나며, 섹션 헤더를 클릭하면 접기/펼치기가 가능합니다._

### **8. 환경변수 설정하기**

메시지 입력창의 \*\*`+` 버튼 → "환경변수"\*\*를 클릭하면 프로젝트 설정 모달이 열립니다. 웹사이트에서 사용하는 API 키, 시크릿 등을 안전하게 관리할 수 있습니다.

#### **사용 방법**

1. **`+ 행 추가`** 버튼을 클릭하여 새 환경변수를 추가합니다.
2. **Key**(변수명)와 **Value**(값)를 입력합니다.
3. 민감한 정보인 경우 **Is Secret** 토글을 활성화합니다.
4. **저장** 버튼을 클릭하여 변경사항을 반영합니다.

> _**ℹ️ 참고** 변수명에 KEY, SECRET, TOKEN, PASSWORD, CREDENTIAL, AUTH가 포함된 경우 자동으로 시크릿으로 설정됩니다. 환경변수를 저장하면 개발 서버가 자동으로 재시작됩니다._

### **10. 버전 관리하기**

주소 바 우측의 **버전관리 버튼**을 클릭하면 웹사이트의 변경 이력을 확인하고 특정 버전으로 되돌릴 수 있습니다.

### **11. 웹사이트 발행하기**

웹사이트 제작이 완료되면 화면 우상단의 **발행하기(☁️) 버튼**을 클릭하여 실제 URL로 배포할 수 있습니다.

<div align="left"><figure><img src="../.gitbook/assets/image (764).png" alt="" width="370"><figcaption></figcaption></figure></div>

> _ℹ️  중요_
>
> 발행된 웹사이트 앱은 발행 운영 기간 동안 일 30크레딧이 차감됩니다. \
> 발행 당일 발행을 철회한 경우에도 해당 일자는 크레딧 차감 대상에 포함됩니다.

#### **발행 절차**

1. **발행하기** 버튼을 클릭하면 발행 팝업이 열립니다.
2. 발행 사유를 입력합니다(선택)
3. **발행 승인 요청** 버튼을 클릭하면 배포가 시작됩니다.
4. 배포가 완료되면 **라이브 URL**이 생성되며, 복사 버튼으로 URL을 복사할 수 있습니다.
5. 추가 작업이 진행되어 새 버전 발행이 필요할 경우 최신 작업 버전으로 신규 버전 발행 요청을 할 수 있습니다. \
   (웹사이트의 발행 운영 중단이 필요할 경우 발행 철회 요청 기능을 통해 발행 취소가 가능합니다)\
   ![](<../.gitbook/assets/image (765).png>)

#### **코드 보안 점검**

발행 요청시 생성된 코드에 대해 **자동 보안 점검**이 수행됩니다. \
잠재적 취약점·경고가 발견되면 발행 단계에서 결과가 표시되어, 안전하게 배포할 수 있도록 돕습니다.

보안 점검 및 발행 요청이 완료되면, 발행하기 팝업 내 "돋보기" 버튼을 클릭하여 상세 내용을 확인할 수 있습니다.

1\. 검출 항목 탭에서 위치와 권장 조치를 확인합니다.\
2\. AI에게 요청하거나 Code 탭에서 직접 코드를 수정합니다.\
3\. 새 버전을 배포하면 변경된 코드로 점검이 다시 수행됩니다.

> _ℹ️  중요_
>
> _보안 점검 결과는 발행 요청에 영향을 주지 않습니다._ \
> _발행 요청은 결과와 무관하게 정상적으로 완료되며, 점검 결과는 참고 정보로만 제공됩니다._

#### **발행 진행 상태**

#### **발행 철회(Unpublish)**

운영 중인 웹사이트를 다시 비공개 상태로 되돌릴 수 있습니다.

1. 발행 팝업에서 **발행 철회 요청** 버튼을 클릭합니다.
2. 확인을 위해 안내된 문구를 입력하고 **철회 사유**를 작성합니다.
3. 요청이 처리되면 라이브 URL 접근이 중단됩니다.

> _**ℹ️ 워크스페이스 발행 승인 면제**_ \
> _관리자가 워크스페이스별로 발행 승인 절차를 면제하도록 설정한 경우, 승인 대기 없이 즉시 배포됩니다. (시스템 관리자 설정 항목)_

### **13. 크레딧 사용량 확인**

에디터 상단(주소 바 영역)에서 현재 앱이 사용한 누적 크레딧과 워크스페이스 잔여 크레딧을 상시 확인할 수 있습니다.

* **이 앱 사용량**: 해당 웹사이트 앱이 지금까지 사용한 누적 크레딧
* **잔여 크레딧**: 워크스페이스에 남은 크레딧
* AI 작업(턴)이 완료될 때마다 사용량이 즉시 갱신됩니다.

또한 매 작업마다 LLM 모델 토큰 사용에 따른 작업별 크레딧 사용 현황을 수신 메세지 하단의 토글을 통해 확인할 수 있습니다.
