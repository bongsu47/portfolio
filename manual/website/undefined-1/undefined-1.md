# 멘션(@)

메시지 입력창에서 `@`를 입력하면 사전 연동한 앱, 파일, 도구를 참조할 수 있습니다.

<figure><img src="../../../.gitbook/assets/image (757).png" alt=""><figcaption></figcaption></figure>

### 사용 방법

1. 메시지 입력창에서 `@`를 입력합니다.
2. 참조할 앱, 파일, 도구를 선택합니다.
3. `Enter`를 눌러 멘션을 추가합니다.

멘션으로 특정 요소를 지정해 AI에 작업을 요청할 수 있습니다.

{% hint style="info" %}
멘션은 **연동 관리**에서 앱, 도구, 모델을 미리 연결한 경우에만 사용할 수 있습니다.
{% endhint %}
