# 요소 선택(셀렉터)

메시지 입력창 아래의 **선택(셀렉터)**&#xC73C;로 요소 선택 모드를 시작합니다.

Preview에서 수정할 요소를 선택한 뒤 AI에 작업을 요청할 수 있습니다.

### 사용 방법

1. 메시지 입력창 아래의 **선택(셀렉터)**&#xC744; 선택합니다.
2. Preview에서 커서가 십자 모양으로 바뀝니다.
3. 수정할 요소 위에 마우스를 올립니다.
4. 녹색 오버레이와 요소 정보 툴팁을 확인합니다.
5. 요소를 선택한 뒤 수정 요청을 입력합니다.
6. 메시지를 전송합니다.

선택한 요소는 입력창 위에 선택 칩으로 표시됩니다.

### 선택 칩 관리

<div align="left"><figure><img src="../../../.gitbook/assets/image (760).png" alt="" width="375"><figcaption></figcaption></figure></div>

* 칩에 마우스를 올리면 컴포넌트 경로, DOM 구조, 소스 파일 위치를 확인할 수 있습니다.
* 각 칩의 **✕**&#xB97C; 선택하면 해당 선택을 해제합니다.
* **전체 해제**로 모든 선택을 초기화할 수 있습니다.
* 요소를 차례로 선택해 여러 항목을 함께 수정할 수 있습니다.

{% hint style="info" %}
수정할 요소를 직접 선택하면 AI가 대상의 위치와 스타일을 정확히 파악합니다.
{% endhint %}
