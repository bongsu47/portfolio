### 모드 선택

<table><thead><tr><th width="80.5390625">모드</th><th>사용 시점</th></tr></thead><tbody><tr><td><strong>Auto</strong></td><td>요청에 맞는 모드를 자동으로 선택할 때 사용합니다.</td></tr><tr><td><strong>Build</strong></td><td>코드를 직접 수정해 빠르게 결과물을 만들 때 사용합니다.</td></tr><tr><td><strong>Plan</strong></td><td>요구사항을 정리하고 개발 계획을 먼저 세울 때 사용합니다.</td></tr><tr><td><strong>Design</strong></td><td>색상, 폰트, 테마 등 시각 디자인을 조정할 때 사용합니다.</td></tr></tbody></table>

{% hint style="info" %}
스크린샷을 첨부해 제작이나 수정을 요청할 때는 **Design** 모드를 선택하세요.
{% endhint %}

### Design 모드

Design 모드를 선택하면 디자인 패널이 열립니다.

<table><thead><tr><th width="168.30078125">기능</th><th>설명</th></tr></thead><tbody><tr><td><strong>글로벌 테마</strong></td><td>색상, 폰트, 테마 프리셋, 모서리, 그림자를 한 번에 조정합니다.</td></tr><tr><td><strong>요소별 편집</strong></td><td>선택한 요소의 타이포그래피, 외형, 레이아웃을 조정합니다.</td></tr><tr><td><strong>시안 선택</strong></td><td>AI가 제안한 디자인 시안을 Preview에서 비교하고 선택합니다.</td></tr><tr><td><strong>이미지 생성</strong></td><td>디자인에 필요한 이미지를 생성해 바로 사용합니다.</td></tr></tbody></table>
