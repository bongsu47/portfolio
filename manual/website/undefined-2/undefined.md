# 코드 편집기

메인 워크벤치에서 **Code** 탭을 선택하면 소스코드를 확인하고 편집할 수 있습니다.

<figure><img src="../../../.gitbook/assets/image (763).png" alt=""><figcaption></figcaption></figure>

### 파일 트리

왼쪽 파일 트리에서 프로젝트의 폴더와 파일 구조를 확인합니다.

* **검색**: 상단 검색창에서 파일이나 코드 내용을 찾습니다.
* **우클릭 메뉴**: 파일이나 폴더를 우클릭해 관리 작업을 수행합니다.

<table><thead><tr><th width="110.5">메뉴</th><th width="288.08984375">설명</th></tr></thead><tbody><tr><td><strong>새 파일</strong></td><td>새로운 파일을 생성합니다.</td></tr><tr><td><strong>새 폴더</strong></td><td>새로운 폴더를 생성합니다.</td></tr><tr><td><strong>복사</strong></td><td>파일 경로를 클립보드에 복사합니다.</td></tr><tr><td><strong>이름 바꾸기</strong></td><td>파일 또는 폴더 이름을 변경합니다.</td></tr><tr><td><strong>삭제</strong></td><td>파일 또는 폴더를 삭제합니다.</td></tr></tbody></table>

### 코드 편집기

파일 트리에서 파일을 선택하면 오른쪽에 **Monaco 편집기**가 열립니다.

코드를 수정하고 저장하면 **Preview**에 즉시 반영됩니다.
