# 데이터베이스 관리

메인 워크벤치에서 **Database** 탭을 선택하면 웹사이트에서 사용하는 데이터를 관리할 수 있습니다.

<figure><img src="../../../.gitbook/assets/image (823).png" alt=""><figcaption></figcaption></figure>

#### **주요 기능**

<table><thead><tr><th width="136.1953125">기능</th><th width="490.02734375">설명</th></tr></thead><tbody><tr><td><strong>테이블 생성</strong></td><td>좌측 목록에서 새 테이블을 추가합니다.</td></tr><tr><td><strong>행/열 추가</strong></td><td>우클릭 메뉴를 통해 행 또는 열을 추가합니다.</td></tr><tr><td><strong>셀 편집</strong></td><td>셀을 클릭하여 텍스트, 숫자, 날짜, 불린 값을 직접 입력합니다.</td></tr><tr><td><strong>CSV 다운로드</strong></td><td>상단의 다운로드 아이콘을 클릭하여 테이블 데이터를 CSV로 내보냅니다.</td></tr></tbody></table>
