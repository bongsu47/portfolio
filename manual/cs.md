# 미소 CS봇

### 열기  &#x20;

1. 화면 우측 하단의 CS봇 버튼을 클릭하면 창이 열립니다.
2. 버튼은 드래그해서 위치를 옮길 수 있고, 위치는 저장됩니다.
3. CS봇 위젯은 미소의 모든 페이지에서 즉시 사용 가능합니다.

<div align="left"><figure><img src="../.gitbook/assets/CS봇 위젯.png" alt="" width="563"><figcaption></figcaption></figure></div>

### &#x20;질문하기 (Q\&A)

1\. 질문하기 탭에서 궁금한 내용을 입력하고 전송합니다.

2\. AI가 실시간으로 답변해 줍니다. (이어서 추가 질문 가능)

3\. 화면 캡처 등 파일을 첨부해 질문할 수도 있습니다.

4\. 답변이 도움이 됐는지 👍 / 👎 피드백을 남기면 품질 개선에 반영됩니다.

<div align="left"><figure><img src="../.gitbook/assets/image (758).png" alt="" width="188"><figcaption></figcaption></figure></div>

{% hint style="info" %}
_💡 질문은 구체적으로 적을수록 정확한 답을 받습니다._
{% endhint %}

### 이슈 등록하기 (오류·개선 요청)

_답변으로 해결되지 않거나 제보할 버그 or 기능 개선 요청이 있으면 이슈 등록 탭에서 접수합니다._

1\. 유형 선택 — 버그 및 오류 / UX 개선 / 기능 추가

2\. 제목과 상세 설명 작성 (재현 방법·기대 동작을 함께 적으면 좋아요)

3\. 필요 시 화면 캡처/파일 첨부&#x20;

4\. 등록하면 미소 운영팀에 자동 전달되어 검토됩니다.

<div align="left"><figure><img src="../.gitbook/assets/image (759).png" alt="" width="188"><figcaption></figcaption></figure></div>

{% hint style="info" %}
_한 건당 하나의 이슈만 적어주세요. 등록할 내용이 많을 경우 각 이슈마다 따로 등록하면 추적이 쉽습니다._
{% endhint %}

### 참고  &#x20;

1. 대화 기록은 위젯에서 다시 확인할 수 있습니다.
2. 민감한 개인정보는 입력하지 않습니다.
3. 등록한 이슈는 담당팀이 검토 후 진행하며, 처리에는 시간이 소요될 수 있습니다.
