# \[레벨 1] 1개 기사로 기업 분석 보고서 작성하기

> **ℹ️ 이 레벨의 목표**
>
> 이번 레벨의 목표는 **네이버 뉴스 검색 도구를 MISO 워크플로우에 연결하고, LLM 노드로 기업 분석 보고서를 자동 생성하는 흐름을 완성하는 것**입니다. 기업명 하나를 입력하면 최신 뉴스 기사를 검색하고 분석 보고서를 출력하는 워크플로우를 단계별로 만들어봅니다.

***

이번 레벨에서 완성할 워크플로우는 다음과 같습니다.

```mermaid
flowchart LR
    A([🟢 시작\ncompany_name]) --> B["📰 네이버 뉴스 검색"]
    B --> C["🤖 LLM\n보고서 작성"]
    C --> D([🔴 종료\nreport])
```

기업명을 입력하면 네이버 뉴스 검색이 실행되고, LLM이 검색 결과를 바탕으로 분석 보고서를 작성합니다. 보고서는 종료 노드의 `report` 변수에 담겨 출력됩니다.

***

미소에 있는 몇가지 도구는 활성화하기 위해서 세팅을 해줘야 할 필요가 있습니다.

이번에 활용할 네이버 뉴스 도구의 경우, 네이버 개발자 API를 활용하기 때문에 아래의 가이드를 참고하여 도구를 활성화해봅시다!

### 1단계. 네이버 개발자 센터 API 발급

네이버 뉴스 검색 기능을 사용하려면 먼저 네이버 개발자 센터에서 API 키를 발급받아야 합니다.

다음의 링크에 접속해봅시다.

[https://developers.naver.com/apps/#/register](https://developers.naver.com/apps/#/register)



1. 애플리케이션 등록

<figure><img src="../../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

접속하면 애플리케이션 등록 페이지가 나타납니다. 네이버 아이디로 로그인 하신 뒤,

앱 등록을 위해 아래 순서로 입력합니다.

1. **애플리케이션 이름**: 원하는 이름을 자유롭게 입력합니다. (예: `네이버 뉴스 도구`)
2. **사용 API**: `검색`을 선택합니다.
3. **비로그인 오픈 API 서비스 환경**: `WEB 설정`을 선택합니다.
4. **URL**: `http://naver.com` 을 입력합니다.
5. **등록하기** 버튼을 클릭합니다.



2. API 정보 확인하기

<figure><img src="../../../.gitbook/assets/image (1) (1).png" alt=""><figcaption></figcaption></figure>

등록이 완료되면 **Client ID**와 **Client Secret** 값을 확인할 수 있습니다.

이 두 값을 통해 도구 활성화가 이루어지니 별도로 메모해둡시다!

***

### 2단계. MISO 네이버 뉴스 도구 활성화

도구 활성화 이전에는 앱 화면에서 아래와 같이 오류 메시지가 뜨는 것을 확인할 수 있습니다.

<figure><img src="../../../.gitbook/assets/image (2).png" alt="" width="375"><figcaption></figcaption></figure>



이제 MISO 워크플로우에서 네이버 뉴스 검색 도구를 사용할 수 있도록 인증 정보를 연결해봅시다.



<figure><img src="../../../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>

워크플로우 편집 화면에서 우클릭하여 노드 추가를 클릭해줍니다.

노드 선택 패널 좌측의 카테고리 목록에서 **\[도구]** 를 클릭하면 사용 가능한 도구 목록이 나옵니다. 목록에서 **네이버 뉴스 검색**을 찾아 클릭합니다.



<figure><img src="../../../.gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure>

노드가 캔버스에 추가되면, 노드 설정 패널에서 **\[인증 추가]** 버튼을 클릭합니다.



<figure><img src="../../../.gitbook/assets/image (6).png" alt="" width="563"><figcaption></figcaption></figure>

인증 추가 창이 열리면 1단계에서 발급받은 값을 입력합니다.

* **Client ID**: 네이버 개발자 센터에서 확인한 Client ID
* **Client Secret**: 네이버 개발자 센터에서 확인한 Client Secret

입력 후 **\[저장]** 버튼을 클릭합니다.



<figure><img src="../../../.gitbook/assets/image (802).png" alt=""><figcaption></figcaption></figure>

이제 검색어 입력과 도구 설정이 가능해졌네요! 좋습니다 :smile:

***

#### 3단계. 검색 테스트 워크플로우 구성

도구가 제대로 연결되었는지 확인하기 위해 2단계에서 만든 워크플로우에 노드를 추가해 테스트를 진행해보겠습니다.

1. **시작 노드 — 변수 추가**
   1. 시작 노드를 클릭하고 **\[+ 변수 추가]** 를 클릭합니다.
   2. **변수명**: `company_name`
   3. **유형**: 텍스트
2. **네이버 뉴스 검색 노드 — 검색어 연결**
   1. 아까 추가한 네이버 뉴스 검색 노드를 시작 노드와 연결합니다.
   2. 노드 설정 패널에서 **검색어** 항목에 `/`를 입력하고 `시작 - company_name`을 선택합니다.

<figure><img src="../../../.gitbook/assets/image (803).png" alt=""><figcaption></figcaption></figure>

3. **종료 노드**
   1. 네이버 뉴스 검색 노드 오른쪽에 종료 노드를 추가합니다.
   2. 출력 변수명은 `result` 로 하고, 연결 변수에 `네이버 뉴스 검색 - text` 를 선택합니다.

<figure><img src="../../../.gitbook/assets/image (804).png" alt=""><figcaption></figcaption></figure>



이제 결과를 한번 볼까요?

입력창에 확인하고 싶은 기업명을 입력합니다. (예: `GS칼텍스`)

그리고 테스트하기 버튼을 클릭합니다.

<figure><img src="../../../.gitbook/assets/image (805).png" alt=""><figcaption></figcaption></figure>

기사 제목, URL, 날짜 등이 포함된 결과가 나왔다면 도구가 정상적으로 연결된 것입니다.

뉴스 데이터를 가져오는 도구 준비가 완료되었습니다. 이제 이 데이터를 LLM 노드에 연결해서 실제 분석 보고서를 작성하는 단계로 넘어가겠습니다.

***

### 4단계. 보고서 작성 워크플로우 완성

3단계까지 완성한 테스트 워크플로우에 LLM 노드를 추가합니다. 뉴스 검색 결과를 배경지식으로 받아 기업 분석 보고서를 작성해 봅시다.



1. LLM 노드 추가
   1. 네이버 뉴스 검색 노드 오른쪽에 LLM 노드를 추가합니다.
2. 배경 지식 등록
   1. 배경지식 영역을 클릭한 뒤, `네이버 뉴스 검색 - text` 를 선택해줍니다.
3. 시스템 프롬프트 작성
   1. 뉴스 기사를 분석하기 위한 프롬프트를 시스템 프롬프트에 추가해줍니다. 아래와 같이 써넣어보았습니다.

{% code expandable="true" %}
```
당신은 기업 분석 전문가입니다.
뉴스 기사를 바탕으로 기업 분석 보고서를 작성합니다.

아래 규칙을 반드시 지킵니다.
- 제공된 뉴스 기사에 없는 내용은 지어내지 않습니다. 관련 정보가 없으면 '해당 정보 없음'으로 표시합니다.
- 보고서는 반드시 아래 형식을 따릅니다. 형식 외의 문장은 출력하지 않습니다.

[출력 형식]
## {기업명} 뉴스 분석 보고서

### 핵심 요약
{1~2줄 요약}

### 주요 내용
- ...
- ...

### 투자 관점 시사점
{2~3줄}
```
{% endcode %}

4. 사용자 프롬프트 작성
   1. 사용자 프롬프트를 활용하여 배경지식으로 설정해둔 네이버 뉴스 결과를 전달해줍니다.

```
분석 대상 기업: {{#시작.company_name#}}

아래 뉴스 기사를 참고하여 위 기업의 분석 보고서를 작성해주세요.

{{#context#}}
```

<div><figure><img src="../../../.gitbook/assets/image (806).png" alt=""><figcaption></figcaption></figure> <figure><img src="../../../.gitbook/assets/image (807).png" alt=""><figcaption></figcaption></figure></div>

5. &#x20;**종료 노드 추가**
   1. LLM 노드 오른쪽에 종료 노드를 추가합니다.
   2. 종료 노드 설정 패널에서 **\[+ 변수 추가]** 를 클릭하고 아래와 같이 설정합니다.
      1. **변수명**: `report`
      2. **값**: `/`를 입력하고 `LLM - text`를 선택합니다.

<figure><img src="../../../.gitbook/assets/image (808).png" alt="" width="375"><figcaption></figcaption></figure>

***

자 이제, **\[테스트하기]** 버튼을 클릭하고 결과를 한번 볼까요?

간단하게 분석할 기업명은 GS 칼텍스로 설정하여 시도해봅시다.

<figure><img src="../../../.gitbook/assets/image (809).png" alt=""><figcaption></figcaption></figure>

최근 기사를 기반으로 분석 보고서를 잘 써주는 군요. 좋습니다!

***

기업명 하나로 뉴스를 검색하고 분석 보고서를 작성하는 워크플로우가 완성되었습니다.

다만, 지금 방식에서는 너무 제한적인 정보 뿐이라 한계가 많습니다.\
뉴스 검색 결과에서 기사 1개만 분석에 활용되기 때문에, 특정 시점이나 단일 관점의 보도에 편향된 보고서가 나올 수 있습니다.&#x20;

이에 여러 기사를 동시에 분석해야 더 균형 잡힌 시각을 얻을 수 있겠다는 생각이 드는군요!\
레벨 2에서는 반복 노드를 활용해 여러 기사를 순서대로 처리하고, 종합 보고서를 작성하는 방법으로 워크플로우를 고도화해봅시다.
