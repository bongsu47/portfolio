# \[레벨 1] 네이버 뉴스 도구 활성화하기

> **ℹ️ 이 페이지의 목표**
>
> 이번 레벨의 목표는 **네이버 뉴스 검색 API를 발급하고, MISO 워크플로우에서 사용할 수 있도록 연결하는 것**입니다. 레벨 2에서 본격적인 분석 워크플로우를 구성하기 전에, 뉴스 데이터를 가져오는 도구를 먼저 준비해두겠습니다.

***

#### 1단계. 네이버 개발자 센터 API 발급

네이버 뉴스 검색 기능을 사용하려면 먼저 네이버 개발자 센터에서 API 키를 발급받아야 합니다.

네이버 아이디로 아래 주소에 접속합니다.

> **https://developers.naver.com/apps/#/register**

< 네이버 개발자 센터 애플리케이션 등록 화면 >

접속하면 애플리케이션 등록 페이지가 나타납니다. 아래 순서로 입력합니다.

1. **애플리케이션 이름**: 원하는 이름을 자유롭게 입력합니다. (예: `MISO 뉴스 검색`)
2. **사용 API**: `검색`을 선택합니다.
3. **비로그인 오픈 API 서비스 환경**: `WEB 설정`을 선택합니다.
4. **URL**: `http://naver.com` 을 입력합니다.
5. **등록하기** 버튼을 클릭합니다.

< 애플리케이션 등록 폼 — 사용 API: 검색, WEB 설정, URL 입력 화면 >

> **ℹ️ 왜 URL이 필요한가요?**
>
> 네이버 API는 요청이 어디서 오는지 확인하기 위해 등록된 URL이 필요합니다. 실제로 그 주소에서 사용하지 않더라도, `http://naver.com` 처럼 유효한 URL을 입력하면 됩니다.

등록이 완료되면 **Client ID**와 **Client Secret** 값을 확인할 수 있습니다.

< 애플리케이션 상세 페이지 — Client ID, Client Secret 확인 화면 >

이 두 값은 다음 단계에서 MISO에 입력해야 하니 별도로 메모해둡니다.

***

#### 2단계. MISO 네이버 뉴스 도구 활성화

이제 MISO 워크플로우에서 네이버 뉴스 검색 도구를 사용할 수 있도록 인증 정보를 연결합니다.

먼저 새 워크플로우 앱을 하나 생성합니다. MISO 홈 화면에서 **\[새 앱 만들기]** 를 클릭하고 앱 유형으로 **\[워크플로우]** 를 선택합니다. 앱 이름을 입력하고 **\[만들기]** 를 클릭하면 워크플로우 편집 화면으로 이동합니다.

워크플로우 편집 화면에서 캔버스 빈 공간을 마우스 오른쪽 버튼으로 클릭하면 **\[+ 노드 추가]** 버튼이 나타납니다. 클릭합니다.

< 노드 추가 패널 열기 — 캔버스 우클릭 화면 >

노드 선택 패널 좌측의 카테고리 목록에서 **\[도구]** 를 클릭하면 사용 가능한 도구 목록이 나옵니다. 목록에서 **네이버 뉴스 검색**을 찾아 클릭합니다.

< 도구 목록에서 네이버 뉴스 검색 선택 화면 >

노드가 캔버스에 추가되면, 노드 설정 패널에서 **\[인증 추가]** 버튼을 클릭합니다.

< 네이버 뉴스 검색 노드 — 인증 추가 버튼 >

인증 추가 창이 열리면 1단계에서 발급받은 값을 입력합니다.

* **Client ID**: 네이버 개발자 센터에서 확인한 Client ID
* **Client Secret**: 네이버 개발자 센터에서 확인한 Client Secret

입력 후 **\[저장]** 버튼을 클릭합니다.

< 인증 추가 창 — Client ID, Client Secret 입력 화면 >

저장이 완료되면 버튼이 **\[인증 추가]** 에서 **\[인증 완료]** 로 바뀐 것을 확인할 수 있습니다.

< 인증 완료 상태 확인 화면 >

***

#### 3단계. 검색 테스트 워크플로우 구성

도구가 제대로 연결되었는지 확인하기 위해 2단계에서 만든 워크플로우에 노드를 추가해 테스트를 진행합니다.

3개의 노드로 구성합니다.

**\[1] 시작 노드 — 변수 추가**

시작 노드를 클릭하고 **\[+ 변수 추가]** 를 클릭합니다.

* **변수명**: `company_name`
* **유형**: 텍스트

**\[2] 네이버 뉴스 검색 노드 — 검색어 연결**

아까 추가한 네이버 뉴스 검색 노드를 시작 노드와 연결합니다.

노드 설정 패널에서 **검색어** 항목에 `/`를 입력하고 `시작 - company_name`을 선택합니다.

< 검색어 항목에 시작 - company\_name 연결 화면 >

**\[3] 종료 노드**

네이버 뉴스 검색 노드 오른쪽에 종료 노드를 추가합니다.

***

3개 노드가 연결되었으면 **\[테스트하기]** 버튼을 클릭합니다.

입력창에 확인하고 싶은 기업명을 입력합니다. (예: `삼성전자`)

< 테스트 실행 — 기업명 입력 화면 >

잠시 기다리면 종료 노드 출력에 뉴스 검색 결과 JSON이 나타납니다.

< 뉴스 검색 결과 JSON 출력 화면 >

기사 제목, URL, 날짜 등이 포함된 결과가 나왔다면 도구가 정상적으로 연결된 것입니다.

***

네이버 뉴스 도구가 준비되었습니다. 레벨 2에서는 이 도구를 워크플로우에 연결해 Five-Forces 분석을 시작해봅시다.
