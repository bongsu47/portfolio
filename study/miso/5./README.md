# 5. 기상청 데이터로 지역별 보고서 작성하기

GS리테일 OFC매니저인 장매니저는 날씨 흐름을 읽어 물품별로 다음주 발주량을 선제적으로 조정하는 것이 주요 없무 중 하나입니다.

매주 금요일 오전9시, 그는 출근 후 자리에 앉자마자 기상청 중기 예보 사이트에 들어가 날씨와 강수 확률을 검토하고, 우산이나 음료, 삼각김밥 같이 날씨에 민감한 품목의 발주량을 조정한 보고서를 오전 시간 동안 작성하여 팀에 공유해왔습니다.

보고서 작성 한 달차가 되자, 어느날 팀장님께서 자리로 부르시더니 업무 지시를 주셨습니다.

> "장매니저, 날씨 기반 보고서 생각보다 반응이 좋은데? 이거 서울 지역만 하는 것에 머무르지 말고, 전국 권역으로 넓힌 다음에 각 지역 담당자들한테 배포해주는 걸로 확장해보자."

자리로 돌아온 장매니저는 눈앞이 캄캄해졌습니다.

서울 한 곳의 예보를 확인하고 관련 보고서를 만드는 데에 꼬박 하루 반나절이 걸리는데, 이걸 전국 여러 권역의 날씨를 각각 수집하고, 또 지역별로 날씨에 맞는 보고서를 만드는 일이라면 금요일 하루 종일 반복 작업만 해야할 판이었습니다.

이에 장매니저는 고민에 빠집니다.

_**'권역별로 날씨를 자동으로 수집하게 만들고, 보고서 양식은 사실상 같으니까, 내용만 지역별로 맞춰서 자동으로 발주 보고서를 한번에 만들게끔 하면 반복 작업을 피할 수 있지 않을까?'**_



이번 장에서는 여러 지역의 기상 데이터를 자동으로 수집하고, 날씨와 강수 확률에 따라 품목별 발주량이 정리된 보고서를 지역별로 자동 생성하는 워크플로우를 구성해봅니다.
